# 产品背景与核心价值：NetCare RFC 方案与 AI 审计

## 痛点与挑战
网络重大工程割接方案（RFC）通常包含数十个章节、海量命令参数、复杂的逆向回退步骤、KPI 指标与附件文本。
传统人工审计面临三重挑战：
1. **耗时耗力**：一份方案数百页，包含各类 TXT、Word、ZIP 附件，人工核查逐行对照极度耗费精力。
2. **规则易漏**：操作前后是否有确认查询？回退命令是否具体？KPI 阈值是否明确？人为审核标准不一，极易产生疏漏风险。
3. **证据难留**：缺乏规范的审计留痕、现场截图凭据与可复溯的归档机制。

## 核心解决方案：NetCare RFC 方案与 AI 审计插件
基于 Chrome / Edge Manifest V3 架构，运行于安全内网沙箱，无需外传核心密钥与方案凭据。

### 核心功能与技术亮点：
1. **无感智能采集与章节树引擎**
   - 注入隔离式 Worker，一键批量解析 NetCare 在线方案与 Word DOCX。
   - 智能目录层级映射（章节树联动，父子继承与名称模糊纠错）。
   - 自动识别提取正文、TXT 与嵌套附件，并发加速。

2. **多协议 AI 审计中枢**
   - 原生对接 OpenAI、Anthropic、Gemini 及本地内网大模型（DeepSeek、Qwen、LLaMA）。
   - 独立配置每章节 4000 字符专属审核 Prompt（如 3.3 操作步骤、3.4 测试验证、3.5 失败回退）。
   - 敏感信息（Token、Cookie、Key、Password）本地自动脱敏。

3. **三态确定性合规判定**
   - 严格三态输出：PASS（完全合规通过） / FAIL（明确违规拦截） / NEEDS_REVIEW（材料缺失或需人工复核）。
   - 强制中英双语结论与五项精简缺陷定位，杜绝大模型幻觉与模棱两可。

4. **完整证据链与自动化归档**
   - 真实 DOM 高清分屏截图存证（html2canvas 离线渲染）。
   - 自动化导出五列表格标准 XLSX 报告（防公式注入、冻结表头、合并单元格）。
   - 一键打包完整材料 ZIP（原始 Word + 章节 TXT + 证据截图 + JSON 轨迹）。
   - AES-256-GCM 高强加密配置备份与 IndexedDB 历史快照时间机器。
