# 素材来源与混音

- 语音：Edge TTS `zh-CN-XiaoxiaoNeural`，-2% 语速；作者原稿，分句停顿与实际逐词时间同步字幕。
- 音乐：scripts/v2/score.py 原创固定谱面，Rhodes 泛音、木琴、稀疏低音；无第三方采样、无循环商用音乐。
- 角色：scripts/v2/mascot.js 原创“小码”，黑白终端与薄荷绿配色；不使用官方 Codex 标志。
- 图形：原创 SVG，依据 RFC 2328 / RFC 3101 及所列厂商文档；蓝色为控制信息，绿色为选中结果或转发，珊瑚色为限制，数字及限定条件明确。
- 混音：人声 RMS 匹配、配乐 120Hz 高通 + 2.2kHz/-7dB 宽带 carve + 6.5kHz 低通，实际语音能量驱动的平滑 duck、淡入淡出、最终 -16 LUFS / -1.5 dBTP 目标；无密集鼓点或抢占语言频段的主旋律。
- 二进制音频和渲染结果被 Git 忽略，成品仅通过独立媒体仓库发布。
