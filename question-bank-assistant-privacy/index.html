适用范围与产品定位Scope & Product Definitions

本隐私政策统一适用于 Tools Platform 提供并发布的以下浏览器扩展程序：

This Privacy Policy applies to the following browser extensions developed and distributed via Tools Platform:

  • 题库与答题助手 (Question Bank & Answer Assistant)Question Bank & Answer Assistant： 用于在自有或获授权的练习页面中管理题目、记录错题、学习翻译解析，并在用户手动启动后提供辅助自动作答。 Designed for authorized practice sites to manage question banks, review mistake histories, study AI explanations, and provide optional automated answer assistance following user command.

Compliance Notice: All extensions are client-side productivity aids. Neither tool guarantees the 100% accuracy of AI answers or audit judgments, nor do they replace manual review or official approval processes. Use only in authorized environments.

03 · Use

数据用途与 AI 传输机制Data Use & AI Requests

  • 纯客户端本地运行Purely Client-Side Execution： 所有文档导出、目录解析、章节纠错、ZIP 打包、截图生成与 Excel 表格排版，均由扩展内置的纯静态离线代码在浏览器本地沙箱中直接完成，无需云端依赖。 All document exports, directory scans, ZIP bundling, canvas screenshots, and Excel generation are processed locally via offline-bundled JavaScript within the browser.
  • AI 交互默认关闭与按需发起AI Features Off By Default： 两款扩展的 AI 模块默认均处于停用状态。只有在用户主动在设置中添加模型、填写 API Key 并明确启动时，才会发起模型通信。关闭 AI 开关后，所有网络请求立即终止。 All AI modules are disabled by default. Network requests are made strictly after the user adds endpoints, provides credentials, and clicks execution. Toggling AI off ceases all model requests.
  • 传输内容最小化与自动脱敏Minimization & Automated Redaction： 发送往 AI 模型的请求仅包含所选题目文本或章节正文证据。在发起网络请求前，扩展内置脱敏引擎会自动扫描并抹除密码、Bearer Token、Cookie、私钥及 Authorization 头。 Requests transmit strictly the selected question texts or chapter evidence. The built-in redaction engine automatically strips passwords, bearer tokens, cookies, and secret keys prior to dispatch.
  • 响应数据安全求值Safe Data Evaluation： 大模型返回的内容仅被作为纯文本或 JSON 数据反序列化，提取答案选项或复核结论，绝对不当作远程 JavaScript 代码执行（无 eval()，无动态注入）。 Model responses are processed strictly as text/JSON data and never executed as dynamic code (no eval() or script injection).

06 · Retention

存储期限、备份与删除Retention, Exports & Deletion

  • 本地持久化与容量控制Local Storage Lifecycle： 题库数据与 NetCare 审计快照持久保存在本地存储中。NetCare 材料缓存（二进制附件）设有 24 小时生命周期及 500MB 安全上限，到期或超额将按 LRU 机制自动淘汰旧快照。 Data persists in local browser storage. Binary material caches have a 24-hour expiration and 500MB ceiling, pruning aged items automatically.
  • 凭据会话存储Credential Session Isolation： 解锁密钥与大模型 API Key 仅暂存于受限的浏览器扩展会话存储中，关闭浏览器或手动点击锁定后立即销毁，不持久化至磁盘。 Unlock keys and API keys reside in browser extension session memory, cleared immediately upon browser closure or manual locking.
  • 导出与删除控制Export & User Deletion： 用户可随时在界面中重置题库、清理材料快照或清空日志。卸载浏览器扩展将立即物理清除扩展自身在浏览器中创建的所有存储空间。 Users can reset banks, delete snapshots, or flush logs at any time. Uninstalling the extension completely purges all local storage.
07 · Security

数据安全与加密技术Security & Encryption Standards

扩展采用现代密码学标准保障用户本地数据安全：

Extensions employ robust cryptography to protect local data:

  • AES-256-GCM 高强度加密：题库保险库与配置导出备份均采用 AES-256-GCM 认证加密算法，具备强防篡改性。AES-256-GCM: Encrypted vaults and backups utilize AES-256-GCM authenticated encryption.
  • PBKDF2-SHA256 密钥派生：采用至少 210,000 ~ 600,000 次哈希迭代及高熵随机盐，有效防御离线彩虹表与暴力破解。PBKDF2-SHA256: Derives keys using 210,000 to 600,000 iterations with random salt.
  • 环境隔离 (World Isolation)：敏感跨域网络通道与配置管理运行于独立扩展上下文中，阻断宿主网页恶意脚本的直接访问。World Isolation: Secure network pipelines and settings operate in isolated extension worlds to block hostile page scripts.
