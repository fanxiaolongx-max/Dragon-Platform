桌面端 License 授权总台账

全量检索已签发的桌面端授权。按设备硬件指纹绑定，支持一键快捷续期、精确改期、机器换绑与停用归档。

签发桌面端 License

按设备硬件指纹统一签发 Windows / macOS / Linux 桌面端授权。将用户提供的设备机器码填入下方，系统将自动校验其硬件指纹并生成数字签名密钥。

签发新授权

提示：此 License（以 DSKL1. 开头）只对上述设备有效，发给用户在桌面端粘贴即可。

💡 签发指引与规范说明

1. 设备机器码规范：
以 DPMC1. 开头，内置操作系统平台、硬件特征摘要与校验位。粘贴后系统会自动解析主机名与防伪指纹。
2. 本地离线与网络防篡改：
授权密钥内嵌 Ed25519 非对称数字签名。即使电脑完全断网也能在本地极速校验，换到其他电脑立即拒绝。
3. 设备重复绑定保护：
如果输入机器码对应设备已有有效授权，解析区域会给出黄色警示，可直接在台账或审批中选择续期原记录。
