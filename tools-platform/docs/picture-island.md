# 图屿 · Picture Island

入口为 `/tools/picture-island`。它作为内置自定义工具随服务启动同步安装到当前租户，在首页工具列表中搜索“图屿”即可打开。新增源码后需要重启服务完成安装；无需单独上传 HTML。

## 日常使用

- 上传：选择多张图片、拖入页面，或直接粘贴截图。默认每张单独收藏；同一海报的多个稿件可在上传框中选“这一批是同一作品的不同版本”。已收藏图片点开后选择“新版本”，继续追加，不覆盖旧稿。同一作品内相同原图不会重复新增版本。
- 找图：搜索名称、分类、标签、备注、版本文件名、版本说明或 AI 识别关键文字；历史版本同样参与检索。工作、生活、收藏和分类入口可进一步筛选。
- 对比：打开图片选择“并排对比”或“叠加对比”，再选择两个版本。叠加模式可调整透明度。不同尺寸按完整画面等比适配，比例不同的版本不保证像素对齐；精确细节可下载原图查看。
- 整理：标题、分类、标签和地点备注均可手动修改；允许新建分类。归档会隐藏整件作品及其版本，可随时在“已归档”恢复，不删除原始数据。
- 分享：下载原图或压缩图；支持文件分享的浏览器可打开系统分享面板，否则下载压缩图后自行发送。分享不创建公开访问链接。

## 压缩与 AI

支持 PNG、JPEG、WebP，单张上限 25 MB，每批最多 50 张。PNG/JPEG 解码上限为 1600 万像素；WebP 由浏览器生成最长边不超过 2400px 的 JPEG 栅格供服务端处理，原始 WebP 保留。动画 WebP 预览仅保存浏览器绘制的静态画面。

服务器在工作线程生成最长边 384px 缩略图、1600px 预览图、1024px 均衡识别图和 1536px 精细识别图，均不放大小图。手机 JPEG 的 EXIF 旋转方向会应用到预览；JPEG 预览将透明区域合成在白底上，原始文件保持不变。衍生图以显示和识别为目标，小图片的衍生文件大小可能高于原始文件。

AI 使用平台当前租户已配置的模型，需该模型支持图片输入。默认不自动发送图片；勾选上传后的 AI 整理，或在详情中点击识别前，须确认图片不含密码、凭据、密钥等秘密。

每次仅发送一个版本的识别图和已有分类，不发送原图及其他历史版本。均衡模式最长边 1024px、输出上限 650 token，适合一般分类；精细模式最长边 1536px、输出上限 1000 token，适合菜单小字。识别关注搜索关键词，不是全文 OCR 或自动翻译，可能漏字、误识别，建议检查后采用。图像 token 由模型计费规则决定，JPEG 字节数减小不意味着 token 同比例减少。

当前版本、当前精度已保存的识别结果直接复用；切换精度可重新识别。一次识别不自动切换其他模型，超时或失败不影响已保存图片，稍后可以手动重试。AI 标题、分类、标签作为建议填入，点击“保存修改”才生效，避免覆盖人工整理。

## 存储与权限

元数据、原图和全部衍生图保存在当前租户 `tools.db` 的 `gallery_categories`、`gallery_items`、`gallery_versions` 表中，不写浏览器本地业务存储，不新增 JSON 数据库。平台当前租户备份包含这些数据；下载工具 HTML/ZIP 只分发代码，不包含图库图片。图片体积较大时，租户数据库与备份也会相应增大。

遵循平台权限：登录用户可查看、搜索、对比、下载和分享；管理员可上传、分类、修改、归档及调用 AI。同租户内图库共享，不是账号私有空间；不同租户无法读取图片或版本。图片响应禁用共享缓存，并要求有效平台登录。
