# 图屿 · Picture Island

入口为 `/tools/picture-island`。主页采用紧凑布局，多选操作栏滚动时保持可见。它作为内置自定义工具随服务启动同步安装到当前租户，在首页工具列表中搜索“图屿”即可打开。新增源码后需要重启服务完成安装；无需单独上传 HTML。

## 日常使用

- 上传：选择多张图片、拖入页面，或直接粘贴截图。默认每张单独收藏；同一海报的多个稿件可在上传框中选“这一批是同一作品的不同版本”。已收藏图片点开后选择“新版本”，继续追加，不覆盖旧稿。同一作品内相同原图不会重复新增版本。
- 全部图片：默认展示所有工作图片（包括已归入相册的工作海报），以及尚未归入相册的生活图片。已归入相册的生活图片继续在“我的相册”查看，搜索仍覆盖全部相册。归档、回收站内的图片不会出现在首页。
- 查看图片：点击后进入铺满浏览器内容区的大图查看器，临时覆盖平台导航和工具栏，关闭后自动恢复。默认隐藏编辑表单；右上角“ⓘ”展开“信息与整理”，可修改名称、分类、相册、标签和 AI 信息。底部缩略图条可切换图片，也可选择“历史版本”；右上角“▧”可收起缩略图，进一步放大观看区域。左右方向键切换当前列表中的图片，Esc 关闭查看器。
- 图片操作：键盘左右方向键、Page Up / Page Down 翻图；鼠标滚轮围绕指针位置缩放，滚轮缩放按屏幕刷新节奏平滑过渡，双指缩放实时跟随手指并保持缩放中心；手势松开或滚轮停下后，接近“适合屏幕 / 适应宽度 / 100% 原始尺寸”时轻柔吸附并显示短暂提示，操作过程中不强制锁住比例。继续缩放即可离开吸附点，系统“减少动态效果”设置会关闭缩放缓动。百分比按原图像素尺寸计算。按住左键拖动图片，Shift + 滚轮保留滚动阅读。手机端双指缩放只作用于图片，不缩放页面；放大后单指拖动平移，未横向放大时单指左右拖动，图片跟随手指并露出相邻图片；松手达到距离或快速划动时翻图，距离不足、取消手势或到达首尾时回弹，长图可上下拖动阅读。版本对比模式保留原有并排/叠加操作。
- 删除：多选后点击“删除所选”，确认后图片及全部版本移入回收站；详情也可删除单张。在回收站多选或打开详情可以恢复。删除与归档分别管理，图片不会因删除操作立即永久丢失。
- 找图：搜索名称、分类、标签、备注、版本文件名、版本说明或 AI 识别关键文字；历史版本同样参与检索。工作、生活、收藏和分类入口可进一步筛选。
- 相册：同一家餐厅的菜单上、下半部，或同一项目的多张图片，放在同一个相册，每张图片仍独立保留自己的历史版本。已有图片点击“选择图片”，勾选后新建或选择相册，再点“归入相册”；也可在详情中修改“所属相册”后保存。移出相册不会删除图片或版本。
- 以后上传同一家餐厅的菜单：在上传窗口选择现有相册；如果是首次上传整套菜单，选择“同一餐厅 / 项目的不同图片（新相册）”，填写餐厅名，每张图片会成为独立页面。只有同一页的新旧稿件才选择“历史版本”。
- 查看整套餐单：进入“我的相册”可一次看到所有菜单页；查看器顶部左右箭头或底部缩略图可连续阅读。相册按名称顺序浏览，可将图片命名为“01_菜单上”“02_菜单下”等来固定顺序。搜索相册名也会找到其中的图片。
- 阅读长图：高度达到宽度两倍的图片，主页卡片和版本缩略图优先放大显示顶部内容。点开后默认适应查看区域宽度，自动加载原图以看清小字；在图片区域内滚动、手机上下滑动即可继续阅读。可用加减按钮缩放，也可切回“查看全图”。已上传的图片同样适用，无需重新上传。
- 对比：打开图片后点右上角“◫”，选择“并排对比”或“叠加对比”，再选择两个版本。叠加模式可调整透明度。不同尺寸按完整画面等比适配，比例不同的版本不保证像素对齐；精确细节可下载原图查看。
- 整理：标题、分类、标签和地点备注均可手动修改；允许新建分类。归档会隐藏整件作品及其版本，可随时在“已归档”恢复，不删除原始数据。
- 分享：下载原图或压缩图；支持文件分享的浏览器可打开系统分享面板，否则下载压缩图后自行发送。分享不创建公开访问链接。

## 压缩与 AI

支持 PNG、JPEG、WebP，单张上限 25 MB，每批最多 50 张。PNG/JPEG 解码上限为 1600 万像素；WebP 由浏览器生成最长边不超过 2400px 的 JPEG 栅格供服务端处理，原始 WebP 保留。动画 WebP 预览仅保存浏览器绘制的静态画面。

服务器在工作线程生成最长边 384px 缩略图、1600px 预览图、1024px 均衡识别图和 1536px 精细识别图，均不放大小图。手机 JPEG 的 EXIF 旋转方向会应用到预览；JPEG 预览将透明区域合成在白底上，原始文件保持不变。衍生图以显示和识别为目标，小图片的衍生文件大小可能高于原始文件。

AI 使用平台当前租户已配置的模型，需该模型支持图片输入。上传默认勾选 AI 整理，可取消；上传窗口明确显示图片会发送到配置的 AI，请勿上传密码、凭据、密钥等秘密。手动设置默认收起，需要时展开。AI 自动补齐名称、用途、分类、相册、标签、说明和版本说明；手动填写或修改的字段优先，并记录字段来源。之前已整理的信息采取保守保护，避免被新识别覆盖。

每次发送当前版本的识别图和精简分类/相册索引，不发送原图。允许自动判断版本关系时，最多额外发送 2 张候选图片的压缩识别图和 6 条候选摘要；明确手动指定保存方式时省去参考图片。均衡模式最长边 1024px、自动整理输出上限 900 token；精细模式最长边 1536px、输出上限 1250 token。识别关注搜索关键词，不是全文 OCR 或自动翻译，可能漏字、误识别，建议检查后采用。图像 token 由模型计费规则决定，JPEG 字节数减小不意味着 token 同比例减少。

当前版本、当前精度已保存的识别结果直接复用；切换精度可重新识别。一次识别不自动切换其他模型，超时或失败不影响已保存图片，稍后可以手动重试。上传时识别结果直接应用到未手动设置的字段，识别失败保留原图并提示稍后重试。同餐厅不同菜单页归入相册，同一画面明确改稿且置信度至少 0.9 时才追加为版本；不能确认则独立保存，避免误并。AI 只能引用当前租户内提供的候选，不能指定任意图片 ID。完全相同的原图在没有手动覆盖设置的自动上传中直接复用，避免重复上传和重复调用。详情中的识别也遵守手动字段优先。

## 存储与权限

用户上传的元数据、原图和全部衍生图保存在当前租户 `tools.db` 的 `gallery_categories`、`gallery_albums`、`gallery_items`、`gallery_versions` 表中，不写浏览器本地业务存储，不新增 JSON 数据库。平台当前租户备份包含这些数据；下载工具 HTML/ZIP 只分发代码，不包含图库图片。图片体积较大时，租户数据库与备份也会相应增大。已有数据库首次访问图库时自动补充相册字段，原图片默认不属于相册；批量归组使用事务，并校验选中图片的版本，避免部分归入或覆盖其他窗口的修改。

遵循平台权限：登录用户可查看、搜索、对比、下载和分享；管理员可上传、分类、修改、归档及调用 AI。同租户内图库共享，不是账号私有空间；不同租户无法读取图片或版本。图片响应禁用共享缓存，并要求有效平台登录。

## 内置示例与远端媒体

图屿随项目内置。首次访问时向当前租户安装 9 组示例、共 11 个图片版本：日料菜单 2 页、网络安全海报 6 张，以及夏令时海报的 3 个历史版本。工作示例仍在“全部图片”展示，菜单收在餐厅相册。示例可改名、整理、移入回收站或恢复；安装记录保存在 SQLite 的 `gallery_example_versions` 表，删除后不会因重启再次出现。已有相同 SHA-256 的图片优先复用，不覆盖用户标题和相册。

`backend/builtin-gallery/catalog.json` 是产品资源清单，`thumbnails/` 是随安装包分发的缩略图（共 435,675 字节）。19,589,505 字节的原图发布在 [Dragon-Platform-Media Release](https://github.com/fanxiaolongx-max/Dragon-Platform-Media/releases/tag/gallery-examples-20261031-v1)，不放入项目安装资源。仅这些特殊示例通过 `example_key` 使用远端原图；普通上传保持原有 SQLite 存储。

列表无需联网。打开示例时按需获取原图，并验证清单大小与 SHA-256；成功后持久缓存在当前租户数据目录的 `runtime/gallery-examples/`，不进入租户备份或桌面安装包。原图、1600px 预览图、均衡及精细 AI 识别图都会在首次需要时生成并写入缓存，后续直接读取本地文件，服务重启后也会复用，不重复下载或压缩。旧 `tmp/gallery-examples/` 中校验通过的原图直接复制到新目录，不重新请求媒体仓库。缓存文件缺失或校验失败时才重新获取或生成；衍生图采用版本化缓存名，修改压缩参数时应升级缓存版本。离线且未缓存时仍显示本地缩略图，清晰原图需联网后重试。预览与 AI 识别图从校验后的原图压缩生成，AI 不直接接收原图。既有用户原图即使标记为示例，也不清除其 SQLite 原始备份。

发布命令为 `npm run gallery:publish-examples`，校验命令为 `npm run gallery:verify-examples`。发布所需原图临时放在 `backend/runtime/gallery-example-publish/`，该目录已从桌面打包范围排除；发布使用不可覆盖的 Release 版本及文件摘要。打包前的 `release:verify-assets` 校验内置清单和本地缩略图。测试或无示例部署可通过 `TOOLS_GALLERY_EXAMPLES=0` 禁用首次安装，不会删除已安装内容。
