# Dragon Claw 数据库权限

首页管理员普通对话可直接通过工具访问当前租户的平台业务 SQLite，包括正在使用的生产业务库，无需选择工作目录。管理员明确要求修改时，工具执行增删改并回读核对；普通对话不开放文件或 Shell 工具。选择工作目录后，还可访问所选项目目录内的本地 SQLite，并按工作区权限模式执行。

普通账号仍只读。普通页面与 WeLink/微信频道的问答仍使用现有只读检索链路；首页的 `@ops-group`、`@welink-office`、`@netcare-data` 专用对话保留各自工具和权限，不叠加平台数据库写入。当前数据库工具支持 SQLite，不支持直接连接任意 MySQL、PostgreSQL 等外部数据库。

以下权限模式适用于已选择工作目录的工作区对话：

| 权限模式 | 查询 | 新增/更新 | 删除 |
| --- | --- | --- | --- |
| 请求批准 `ask` | 自动 | 审批 | 审批 |
| 帮我批准 `auto` | 自动 | 自动 | 审批 |
| 完全访问 `full` | 自动 | 自动 | 自动 |

使用步骤：管理员登录 → 首页普通对话 → 用自然语言指定要修改的平台业务数据。其他本地 SQLite 请先选择其所在工作目录，再选择所需权限模式。改动后 Dragon Claw 应重新读取目标行核对结果。服务端代码更新后需重启后端；桌面发行版需要包含该更新才可使用。

数据库工具：

- `list_databases` 返回当前租户实际使用的库，管理员列表带 `writable: true`。报表按 `TOOLS_REPORT_DATA_DIR` 解析，其余平台业务库按当前租户数据目录解析；不会访问其他租户或扫描备份归档。
- `database_schema` 与 `read_database_table` 查看可用业务表、列与行。AI 月报和知识索引表也开放；聊天记录业务库只对管理员开放。读取结果的 `readOnly: true` 表示本次读取没有写入，`writable` 表示当前账号的数据库写权限。
- `insert_database_row` 新增一行；`update_database_rows`、`delete_database_rows` 按 `filters` 的 AND 条件更新或删除。`values` 使用 JSON 对象字符串，例如 `{"title":"新标题","count":3}`；内部服务也接受对象。
- 更新和删除须有筛选；操作整表需显式传 `allowAllRows: true`。默认直接影响行数上限为 1000，管理员可按任务显式指定 `maxAffectedRows`。

UIVF12 抓取脚本任务优先自动加载 `@script-data`，使用专用脚本查询、分段读取、复制/修改/重建/删除工具，避免通用读表工具的单格截断和 Shell 转义。站点迁移用 `targetSite` 保留数据筛选，分类用 `move_uiv_script` 同步列与页面载荷。通用数据库工具不再直接写平台 `uiv_scripts`；专用工具保留管理员 CRUD 能力并确保元数据一致。写入前校验语法与记录版本，提交后回读；具体见 [内置 Skills](dragon-claw-skills.md)。

写操作使用独立连接、外键约束和事务，执行时重新验证表结构、条件与行数，失败回滚；审批预览不会修改数据。成功返回 `changes`，新增另返回 `lastID`。`changes` 是直接影响行数，不包含外键级联行数。

这是业务数据 CRUD 授权。账号、认证会话、租户注册、凭据与智能体内部状态表仍受保护；敏感列、含凭据的键值配置也受保护。不能跨租户，也不提供任意 SQL 或建表、删表、改表工具。目标表/级联表含触发器，或操作可能级联修改受保护数据时，需使用对应业务 API。

数据库提交不保存为文件快照，不能通过工作区的文件撤销按钮回滚。此更新不修改运行数据库、默认快照或现有工作区的权限模式。

脚本内容是上述凭据写入检查的专用例外：`save_uiv_script` 可在 `uiv_scripts` 中保存鉴权逻辑与内嵌凭据，服务端复制/重建保留完整原文；模型输出和日志仍脱敏。该例外不能通过通用工具的请求参数开启，也不开放其他表、控制面或跨租户访问。修复、同名冲突不代表删除授权，不能用删除旧脚本作为重建的准备步骤。
