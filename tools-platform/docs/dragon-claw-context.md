# Dragon Claw 手动压缩上下文

在首页对话输入 `/`，选择 **`/compact` 压缩当前对话上下文**，或直接输入 `/compact` 后发送。`/compress` 是同义命令。

压缩使用当前选择的模型生成摘要，保留任务目标、已确认事实、约束、完成步骤与待办；最近一轮问答和工作区工具调用/响应配对保持完整。后续模型请求使用摘要与近期内容，不再把已压缩的旧消息原样带回。上下文已经很短时会提示无需压缩。

- 完整聊天、Shell 输出、逐轮工具档案及文件撤销快照不删除，仍可通过 `/session` 查看历史。
- 工作区工具转录也会压缩并持久化，刷新或服务重启后不会被旧检查点覆盖。最近一轮工具签名仍保留。
- 普通用户可以压缩自己的会话；不增加写文件或 Shell 权限，管理员完全访问模式也不改变。
- 执行或压缩中的同一会话禁止并发压缩/发送；可以使用发送按钮的停止状态中止压缩。切换新对话后，迟到结果不会更新新对话界面。
- 模型失败、空摘要、不完整摘要或事务期间发生会话更新时，原上下文保持；摘要与 Agent 快照通过同一 SQLite 事务提交。
- 压缩完成后侧栏清理旧占用数值，下一次实际模型回复再更新占用；不把字符估算冒充真实 token 节省量。

摘要必然会省略细节。涉及更早的精确数值、命令输出或源码时，应重新核对历史或文件，不把摘要当作完整原文。当前摘要输入使用有界节选，避免压缩请求本身无限增长。
