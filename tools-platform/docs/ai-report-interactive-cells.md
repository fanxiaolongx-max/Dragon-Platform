# AI 月报交互格子（大平台试用版）

## 使用

新格子默认生成可执行、可编辑的交互 HTML，无需说明“开启交互”，也不再询问是否需要交互或交互范围。原静态格子继续兼容，不自动改写历史月报。编辑器编译请求明确声明交互模式，后端遇到旧静态配方会要求模型重试，前端再校验实际输出必须包含交互组件且无旧静态组件；旧布局标记只作内容和比例参考。纯文字交互配方也不再被文字展示兼容逻辑改回静态总结。后端更新后需刷新编辑器加载新请求协议；已生成的旧静态格子在“再试一次”时转换。

格子打开即可直接拖动 HTML / SVG 元素，双击无子元素的文字可编辑，Enter 完成、Shift+Enter 换行、Escape 取消。不显示“自由编辑”或编辑模式开关；预览模式只读。普通按钮、输入框、链接保留自身交互，按住 Alt 可拖动这类控件。旧生成页面里重复的编辑模式按钮会隐藏，但保留节点供其脚本引用。

点击月报右上角“保存”后，代码、状态、调整记录和静态快照一起保存到当前租户月报中。原月报撤销功能可撤销已记录的编辑。

拖动或修改文字后，未保存状态、保存按钮和当前右侧最终提示词同步更新，不重建格子或清空聊天输入框。提示词里的 `【手工展示调整】` 是简短说明；精确位移保存在该格子 `output.widgets[].spec.edits`，调整记录保存在 `spec.history`。点击保存前这些改动只在当前页面内存中；保存后随文档写入当前租户 SQLite 的 `ai_report_documents.payload_json`。保存失败可直接重试，保存请求期间产生的新修改仍标记为待保存。

“再试一次”直接使用当前页面的最新最终提示词和编辑记录，无需先保存；开始生成前会收集目标格子的最新 iframe 状态，再进入原编译流程。保存只持久化文档，不触发重新生成，也不重建格子。交互格子自动更新的渲染快照用于导出和生成参考，尺寸变化、选择高亮等导致的快照变化不单独标记为未保存；代码、提示词、位移、文字、交互状态等真实变化仍会标记并保存。撤销记录继续保留完整快照。

编辑即时生效，不调用模型。相同元素的同类调整保留最后结果，最终提示词的“手工展示调整”段落会被替换更新，不逐条追加历史。重新生成时会把当前展示、状态和调整记录作为参考发给模型，允许优化布局；换月仍通过原来的取数与计算链路读取真实数据。

## 配方接口

```js
function render(result, kit) {
    return kit.interactive({
        html: '<h3 data-air-element="title">数字证书</h3><div id="chart" style="height:180px"></div>',
        css: 'h3{margin:0 0 8px;color:#1f5e95}',
        script: 'const chart=echarts.init(document.getElementById("chart"),null,{renderer:"svg"});' +
            'chart.setOption(' + JSON.stringify({
                grid: {left:35,right:12,top:16,bottom:26},
                xAxis: {type:'category',data:result.labels},
                yAxis: {type:'value'},
                series: [{type:'line',data:result.values}]
            }) + ');'
    }, {id:'main',height:240});
}
```

`html`、`css`、`script` 在配方 Worker 中只是字符串，只在独立的展示 iframe 中执行。平台为 html/body/#air-content 提供明确的视口高度，支持 height:100% + flex:1 这类剩余空间布局；固定高度格子按实际可用空间安排 iframe，编辑按钮浮在内容上方，不额外占据高度。图表容器尺寸变化后自动 resize，零尺寸图表会报错，避免只有标题被当成生成成功。内部可自由使用 CSS 布局、脚本和事件。有横纵坐标的 ECharts 图表默认保留轴线、刻度和标签；这是对生成配置主动隐藏坐标轴的兜底。用户明确要求保留自定义隐藏配置时，可以在 `kit.interactive` 的第二个参数中传 `axes:'preserve'`。`echarts` 已内置，无需请求 CDN。任意 HTML 片段中的脚本不会被插入平台主页面。

脚本可调用：

- `airCell.getState()` / `airCell.setState(json)`：读取与保存自定义状态。
- `airCell.getAdjustments()`：读取当前元素偏移与调整历史。
- `airCell.record({element,action,description,before,after})`：记录 AI 自定义交互的修改；description 用简短自然语言描述最终展示要求。
- `airCell.snapshot()`：主动同步状态和静态快照。

主要元素可加稳定的 `data-air-element` 标识。没有标识时编辑器按 DOM 路径匹配，适合保存当前内容；重新生成不保证沿用路径。SVG 内的文字和图形可移动；Canvas 是一整块画布，其内部对象需要 AI 脚本自行实现编辑，故提示词默认要求图表使用 SVG。

## 保存、导出与执行

交互脚本不拥有平台 DOM、Session 或业务 API；iframe 使用 `sandbox="allow-scripts"`，数据通过配方传入，保存消息由父页面核对来源后接收。外部资源和网络请求不属于该运行环境提供的能力。

交互 HTML 导出内嵌运行器与图表库，可离线查看。打印、PDF 与邮件使用运行后采集的静态 HTML/SVG 快照；静态快照清理脚本并保留内联展示样式，复杂动画、Canvas 或浏览器特殊效果的静态还原需要专项适配。脚本的即时错误会显示在格子里，新生成时进入原有修正重试流程；异步或特定点击才能触发的错误仍需实际操作检查。

本版不提供所有图表类型的专门编辑器，也不强求重新生成时精确复现。已覆盖平台通用拖动、文字编辑和脚本状态记录；特殊交互可以由 AI 继续扩展。

## 独立元素拖动与放大编辑

柱状图的柱子和数值标签按当前图表的系列及分类数据项绑定，不包含运营商、产品或月份等特定业务名称。一般 SVG 图形使用内容/形状标识，显式命名重复时按具体元素区分。编辑时关闭图表的高亮动画与淡化，并保留被移动图形在格子内的显示；选中框只标记当前元素，空白 SVG 分组不再被误当成单个柱子拖走。

旧版本按 SVG 节点顺序保存的位移可能在重绘后对应到别的元素；这些不可靠位移不再重放到 SVG 上。已有的这类微调需重新拖动一次，指标数据与计算结果不变。

格子右上角的“放大编辑”图标会动画放大原格子，模糊月报背景，并保留、锁定右侧的当前格子对话。放大/缩回不移动 iframe 的 DOM 位置，不因该操作重新加载脚本。点击模糊背景、右上角退出图标，或在非文字输入状态按 Escape，可动画返回。AI 更新当前格子后仍保留放大状态。普通桌面窗口保留左右布局，小屏幕把对话放到编辑区下方；减少动态效果设置下直接切换。

放大仅改变编辑视口，不写入月报的格子尺寸。导出或打印前恢复月报布局。测试包含非运营商分类、单个标签/柱子拖动、悬停与重绘、重复元素名、放大/退出保留 iframe、对话锁定、AI 式重渲染和窄屏适配。

## 混合内容与两栏对齐

单个交互 HTML 支持混排段落、多张图表、表格和普通控件，各图表容器的标识独立。已用“文字 + 柱状图 + 折线图 + 表格 + 按钮”验证文字编辑、独立图表标签拖动、表格内容移动、控件点击、保存重开与静态导出。复杂内容仍需由生成脚本提供合理布局；Canvas 内部对象和特殊交互不等同于普通 HTML/SVG 元素的通用编辑能力。

桌面端放大编辑的左右两栏共享右侧对话面板的实际顶部和底部，随窗口尺寸和面板尺寸变化同步，不再单独限制左侧高度或垂直居中。小屏幕继续上下排列编辑区与对话。

实际浏览器验收以 `https://cs.fanxiaolong.uk/?app=%2Fmonthly` 的工具中台嵌入入口为准，检查嵌入容器内的放大、缩回、对话锁定和两栏边缘对齐；`/monthly` 独立页只用于模块调试，不能替代最新入口的集成验收。本次已在嵌入入口实测左右两栏顶部和底部差值均为 0px，并验证退出和再次放大。

放大编辑采用等比适配：窗口边缘继续与右侧对话对齐，内部正文保留原始布局宽高，按可用宽高的最小缩放比整体缩放，并在内边距范围内水平、垂直居中。图表、表格和文字一起缩放，iframe 不因编辑窗口的比例重新排版；窗口变动时重新计算适配比例。退出后恢复正文原样式，拖动坐标保持原内容坐标。已覆盖宽格子、竖长格子与编辑记录回归。

柱状图未指定 series.label.show 时默认显示数值标签；明确的 show:false 保留。生成协议要求继续显示手工调整过的数值标签，避免重新生成时因旁边已有数据表而漏掉它们。

重新生成的手工调整恢复：HTML/CSS/JS 改写后，同月原格子的可识别调整会通过锚点重放。柱形图数值标签以系列、分类和对应柱顶为锚点，用字高记录文字中心的相对位置；柱体以自身数据图形中心为锚点。HTML 元素使用稳定 id/data-air-element，或唯一的标签与内容，位置记录为所属容器中的相对比例。文字修改也随匹配元素恢复。多图存在歧义且没有一致容器标识时跳过，并显示未匹配数量；不保证任意重写后都能识别原对象。旧 SVG 节点序号仍不盲目重放。编译上下文把手工调整标为已确认要求，未调整部分仍可重新排版。

表格单元格采用专门的锚点：按表头名称和行内容匹配，用字高记录相对自身原位的偏移，不把向上移动量换算成整行高度的比例。重新生成改变行高、行列顺序或包裹标签时，仍匹配对应表头/单元格；同名表格无法唯一匹配时保留未匹配提示。旧的表格比例记录会根据已保存位移兼容转换。

## 分层选择、组件缩放与表格尺寸

`element-editor.js` 提供平台统一的编辑界面，序列化到沙箱运行；不由模型重复实现拖拽、缩放或选择监听器。普通月报中悬停、选中和拖动只命中顶层内容块。放大编辑时启用精细模式，顶部下拉列表显示自动识别的完整层级，路径按钮可选择父层并锁定命中范围；“自动选择”恢复按鼠标目标选择。层级深度从实际内容推导，不限制 DOM 必须恰好三层。

悬停时显示目标边框与名称，选中后显示角点缩放柄。HTML 内容块调整实际宽高；文字调整字号；SVG 图形调整自身缩放；ECharts 容器改变尺寸后由原有 ResizeObserver 重绘。缩放柄会留在 iframe 可点击区域内。精细模式选中整张表格后，列边界可调整相邻列宽比例，行边界可调整行高，角点可调整表格整体尺寸。表格各列以表头名绑定、各行以内容匹配，重排后仍可恢复。

尺寸保存在交互组件原有 `spec.edits` 中，字段为 `size` 和 `tableLayout`，操作历史使用 `resize`、`column-width:*`、`row-height:*`。新的 DOM 定位使用临时稳定节点标识，插入 colgroup 后不会把已有表头位移应用到别的节点。重新生成时继续通过锚点携带这些字段；表格整体和图表容器有专门的匹配方式。尺寸、字号、列宽和行高即时同步到最终提示词，不需要先保存再重新生成。保存重开和静态/交互导出保留展示，悬停边框、缩放柄及层级工具栏不进入内容快照。

生成协议推荐“内容块 → 组件 → 细节”的语义结构，主要组件提供唯一、稳定的 `data-air-element` 和简短的 `data-air-name`。这是生成约定，已有格子仍会自动识别。一般 HTML/SVG 和原生表格可直接编辑；Canvas 内部对象、跨域 iframe 及无法唯一识别的重写内容仍不能承诺逐项恢复。合并单元格、多行表头等复杂表格需要生成脚本提供明确语义，当前行列尺寸验收覆盖普通原生表格。

## 长内容边界与满格组件

iframe 本身的边界无法通过内部 `overflow:visible` 消除。运行时会测量单 grid 的 ECharts SVG 文字，逐边补足网格留白，让首尾刻度、柱顶数字等留在图表内；不重新排位用户手工移动过的文字。没有空间容纳任意长内容时，保留完整数值并显示实际文字越界数量，用户可增大格子或调整组件。多 grid、非笛卡尔图等复杂布局目前使用溢出检测兜底，不保证自动排好所有内容。

HTML 连续长字符串超宽时改为自然换行并启用 `overflow-wrap:anywhere`；默认宽表在没有手工尺寸记录时可切换固定表格布局，避免被单个长值撑开。生成协议也要求明确边距和换行行为；特殊设计可声明 `data-air-overflow="preserve"` 保留原设置。自动留白与换行只改变展示，不写成用户手工调整，也不应导致保存后又变成未保存。

选中框提供八向缩放拉手，沿组件的可见交集分布并内收进 iframe，不依赖组件外侧有空白。拉手按放大比例反向补偿，屏幕上的目标尺寸保持约 14px；西侧、北侧缩放同步调整位置，保留对边。顶部层级工具栏另有宽高输入，可在组件撑满、超出画布或鼠标难以拖动时直接设置尺寸。位置和尺寸同步记录到提示词与持久化数据。悬停层级标签同样保持在可见区域。
