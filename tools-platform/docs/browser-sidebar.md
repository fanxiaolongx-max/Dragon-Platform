# 对话右侧栏与 Dragon 浏览器

对话顶部的「工作区」「浏览器」分别打开对应侧栏，文件链接打开文件预览。同一时刻显示一种内容，切换后原对话与工作区上下文保留。普通对话、桌面 Agent 和频道借用的工作区均可拖动左边缘调整宽度，也支持聚焦分隔线后用左右方向键调整、Home 恢复默认宽度。工作区和浏览器各自记住宽度；文件预览沿用原有宽度控制。窄屏下以右侧临时抽屉显示，点击面板外区域关闭；AI 操作不自动展开抽屉覆盖对话，需要时点「浏览器」查看。

手机端左侧菜单默认关闭，点击后临时覆盖显示，选择对话、新建对话、点击遮罩或 Esc 后关闭。中间列表独立滚动，账号与通知按钮留在底部。手机操作不改写桌面菜单偏好，跨断点或恢复页面时也不会保持常驻菜单。

每次重新打开浏览器侧栏会临时收起左侧菜单，并按屏幕空间自动分配阅读宽度，为对话保留至少约 360px；宽屏网页优先使用较宽区域；检测到正文居中且两侧留白较大的手机式窄栏排版时，按正文宽度加适当留白收窄侧栏。Web 同时调整实际浏览器视口，保持字号可读，不只是缩小截图。页面导航后重新检测；桌面端与 Web 共用布局检测逻辑，只回传尺寸，不回传网页正文或表单值。浏览期间仍可手动拖动宽度，同一页面的画面更新不会重置手动调整；重新打开或切换新页面时重新适配。关闭侧栏后恢复原菜单状态，自动布局不会覆盖菜单的持久偏好。

浏览器显示期间，网页额度栏和桌面顶部额度栏临时切换到精简、自动收起模式，悬停仍可查看；关闭浏览器或临时切到其他面板后恢复用户原有额度显示偏好。

## 桌面端

浏览器侧栏承载原 Dragon 浏览器的 BrowserView，不创建另一套浏览器存储。已有标签、网页状态、站点登录态和浏览器插件仍使用原持久分区。支持地址输入、多标签、前进、后退、刷新和外部浏览器打开；外部打开在桌面端使用系统默认浏览器，Web 端使用当前浏览器的新标签页；原侧栏页面保留，不分离为独立 Dragon 窗口。

平台 AI 的现有浏览器工具仍控制原 webContents，通过 Dragon 浏览器打开的页面会自动展示到侧栏。外部 Agent 自己的浏览器工具不会因此自动接入。浏览器查找、历史和下载在侧栏内使用，不移到独立窗口。

关闭侧栏仅移除显示，不关闭标签或清除登录态。切到工具页时默认暂时收起；桌面端普通内嵌工具顶部提供「浏览器」按钮，批脚本等主动打开网页后可自动并排展开，保留工具页面与输入状态。独立原生工具视图仍暂停显示浏览器，避免原生视图互相覆盖。打开文件预览、拖动侧栏或显示模态框时，会暂时移除原生网页，避免其盖住平台界面。原生网页左侧为全高拖拽条预留空间，正文区域的左边缘也能调整侧栏宽度。IPC 仅接受本机主窗口首页主 frame 的调用；窗口销毁后到达的消息直接忽略。

桌面批脚本完成后，生成的本机 SLA 自动导入链接回到主窗口已有的内嵌工具区域执行导入，保留暂存会话、目标月份和抓取标签；不新建 Dragon 浏览器导入标签，不复制平台凭据，也不跳过鉴权。导入页沿用主窗口当前账号与租户。仅接收当前本机服务同源、带合法会话参数的 SLA 自动导入链接；普通网页开窗以及 Web/非桌面端的新窗口流程保持原行为。

桌面主进程与 preload 有变更，需要完全退出并重新启动应用。发布包通过 package.json 纳入新增 IPC 模块。

## Web 与手机端：同一个浏览器，人工与 AI 交接

界面只有一个 Dragon 浏览器，不再区分“AI 画面”和“网页预览”。手动输入网址、新建标签与平台 AI 的 `browser_*` 工具共用当前租户、账号的浏览器实例、标签页和登录态。不依赖 iframe，因此站点禁止被嵌入时仍能显示浏览器的实际页面。Skill 是工具使用说明；只有实际调用平台浏览器工具才会操作这套浏览器。外部 Agent 自带的浏览器仍由其自身管理。

- 输入网址或点击新标签可直接开始浏览，无需先让 AI 打开。
- AI 打开的网页会出现在同一侧栏。手机上不自动弹出遮住对话，需要时点“浏览器”查看。
- 顶部不再放“手动接管”按钮。AI 操作时显示彩色指针；用户尝试点击、滚动或键入时，在网页内显示彩色圆角浮动横幅，点击“停止并接管”后，可点按网页画面、滚动、发送文字、回车、退格及切换输入焦点。手机支持滑动画面滚动，开启“拖拽模式（手机）”后可拖动滑块或页面元素；电脑直接拖动画面。画面可放大后定位细小控件。
- 地址栏、标签切换与前进后退会进入人工控制。Web 的刷新按钮刷新当前网页。
- “停止并接管”会中断当前浏览器工具的等待和后续输入，停止页面加载，不等待该工具自然超时。已送达网页的点击或提交无法撤回。人工操作期间等待中的 AI 读取工具暂停；用户空闲后自动交还。曾等待人工控制的旧写操作需先重新读取页面，不自动重放。
- 新交互的人工租约为 **5 秒**，页面里的鼠标、触摸和键盘操作会重置倒计时；中断 AI 后的浮动横幅显示剩余秒数，也可“立即交还”；普通浏览不显示该横幅。画面刷新、心跳不延长人工空闲时间。关闭侧栏会尝试交还控制；断线后也由服务端在租约到期时恢复。相同账号的其他窗口不能抢占有效接管。历史 `acquire` API 保留原租约以兼容旧客户端。

Web 通过连续 JPEG 画面与 CDP 输入显示和控制真实浏览器。侧栏可见时连续传输画面（每帧间隔至少 250ms，实际速度取决于捕获和网络），后台、关闭或切换面板时停止。每条连接最多 45 秒后重建；断线时自动尝试重连，无法流式传输时回退至约每 2 秒刷新。人工按下、移动、松开分别送达同一页面，支持滑块及 HTML5 拖放；断线未松手的动作 10 秒后自动取消。此通道不是高帧率远程桌面，也暂不映射复杂多指手势。

接管后先点击网页里的上传按钮，再点击侧栏“选择文件上传到网页”，可选择电脑或手机文件；电脑也可把文件直接拖入画面上的投放区。文件只送给当前账号的对应网页控件，不写进 AI 对话。复用对话附件类型白名单（包括 PDF）、大小限制（单个 20MB、一次 5 个）、账号/租户目录及 30 天清理机制。网站自身仍决定可接受类型和数量。桌面端直接使用原生页面的文件控件与拖放，无需该上传中转。AI 工作时由独立透明 BrowserView 接收真实用户输入并显示指针、停止横幅，AI 的 CDP 输入仍指向原网页。接管后移除输入遮罩，原生页面显示 5 秒倒计时；可信真实输入通过隔离 preload 通知主进程，网页无法直接调用接管 IPC。

`GET /api/agent-workspace/browser/stream` 使用与画面接口相同的鉴权，单账号最多两条连续连接，慢客户端采用背压，不在 URL 传 Token；`POST /api/agent-workspace/browser/upload` 只接受 multipart 文件和有效人工接管租约，不接受服务器路径。multipart 解析后重新绑定原租户上下文，避免异步解析丢失隔离。

`GET /api/agent-workspace/browser/view` 只读取当前租户、账号已有会话，不创建浏览器。`POST /api/agent-workspace/browser/control` 仅接受管理员、同源请求及限定操作类型；坐标输入绑定画面编号、标签、地址和视口，旧画面不能重复提交。人工输入直接送到浏览器，不进入 AI 工具转录；接管期间不记录供 AI 读取的网络和控制台数据，交还时清空这些缓存，页面快照也不返回密码输入框值。响应不缓存，不写业务数据库。

## 浏览器工具栏与 Windows 窗口边界

侧栏使用两行浏览器工具栏：顶部为可横向滚动的标签、新建、标签列表以及侧栏关闭／外部打开；第二行为后退、前进、刷新、搜索／地址、扩展、下载和更多菜单。标签支持关闭、恢复和拖动排序。Web 的“网页输入与上传”收纳到键盘按钮或更多菜单，默认不展开。

桌面侧栏复用原生浏览器的下载进度与打开／定位文件、扩展管理（ZIP／目录／本机已安装扩展）、历史、收藏、页面查找、打印、缩放、开发者工具及截图保存。Web 支持页面截图保存和画面缩放；暂不提供服务端浏览器下载管理、扩展管理、历史收藏、原生查找和打印，这些入口会说明范围或禁用，不能访问用户 Chrome／Safari 的扩展。

普通浏览不显示“你正在操作”“立即交还”及 AI 倒计时。仅 AI 正在执行浏览器工具或曾被用户强制中断时显示交接横幅；5 秒空闲交还规则保留。`operator.handoff` 用于区分真正的 AI 中断与普通人工浏览。

Windows 非全屏状态给主窗口右上角三键预留 38px 顶部标题行，浏览器自己的按钮在其下方；最大化也保留，全屏时移除。原生网页的挂载边界跟随侧栏实际内容区域，不覆盖标题栏或输入工具。扩展、下载、更多、标签列表使用原生下拉菜单，直接浮在网页上方，不改变页面位置或视口大小。自动化测试在 Mac Electron 中加载真实 Windows 控件样式并切换窗口状态，检查按钮矩形不重叠；Windows 实机仍需发布前验收。

Web 的扩展、下载、更多、标签列表与网页输入工具使用绝对定位的浮动菜单，锚定触发按钮，点击外部或 Esc 收起，不参与页面布局。无标签时只保留 + 入口，不显示可点击的“新标签页”占位；新建后的真实标签仍可切换和关闭。空白页在 Web 使用平台主题底色并隐藏远程空白截图，桌面通过受信任的侧栏 IPC 同步浅色／深色到 about:blank，不修改外部网站的样式。网页输入与上传入口仅在有实际网页时显示，并说明输入不会发送到 AI 对话。

## 连续键盘输入与自动打开入口

Web 键盘输入使用有序队列，短时间连续文字合并提交，保留退格、回车的顺序，不再逐字符等待整张 PNG 截图，也取消文字／按键动作后的固定 180ms 等待。画面仍由连续通道更新，网络与 JPEG 帧间隔带来的延迟仍存在。旧画面在一次操作后不能重复用作坐标点击，但同一文档与视口下仍可继续键盘输入；新文档（含相同 URL 重载）使用独立 documentId，旧输入不能投递过去。明确的过期拒绝最多在重新读取且文档未变化时重试一次，不重试网络不确定错误。桌面原生输入不经过 Web 的逐帧校验链路。

主应用通过 `getSidebarHost` 将登录推广、推广链接点击、AI 页面、站点脚本、批处理与扩展页面的应用打开入口统一路由到主窗口侧栏。默认推广开关仍关闭，沿用已有 desktopStack 配置键；启用后只创建推广标签，不创建右下角置顶卡片窗口，不按定时器切换正在阅读的网页。相同配置重复同步不重复开标签；暂停／关闭推广仅移除推广标签，保留用户与 AI 标签。首页在此模式下使用封面，不再循环请求旧卡片实时截图。主动外部打开也不分离 Dragon 页面：桌面调用系统默认浏览器，Web 使用当前浏览器新标签页。旧 popout IPC 兼容转为外部打开。
