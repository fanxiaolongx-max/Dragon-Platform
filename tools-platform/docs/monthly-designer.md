# 原始表资料库与独立月报编辑器

入口：导入数据页完成原始存档后，点击「打开数据资料库与月报编辑器」；报表看板和旧月报页也有「护网与网络安全月报」入口。页面地址为 `/pages/monthly-designer.html`。旧版基于月报的 `monthly-template` 实现已移除。

## 从导入源头存档

全局设置 → 数据导入 →「原始数据上传到服务器」默认开启，按当前租户保存并自动生效。每次手工/自动导入先读取服务器开关；关闭时跳过原始文件及完整工作表存档，仍按原逻辑提取指标、保存快照和对应清洗结果，不删除已存档的原始表。重新开启仅影响之后的导入，不补存关闭期间的文件。开启时，多月份文件完整保存，目标月份筛选只影响提取和快照，不裁剪原始文件或工作表。

1. 手工选择 CSV/XLS/XLSX 后，先把所有选中的文件按原始字节存入当前租户的 SQLite。然后保存各工作表的表头与行数据，最后才进行现有的月份筛选、清洗和指标提取。
2. 未配置规则、未匹配目标月份、未成功解析的文件也保留。解析失败会显示状态；仍可以下载原文件。单文件上限 128 MB，解析数据沿用平台 50 MB JSON 请求上限；超出解析上限时原文件仍然保留。
3. UIVF12 自动导入目前向导入页提供结构化行，并未提供下载前的原文件字节。资料库保存这些行及重建 CSV，并明确标记「自动抓取的结构化表（CSV 重建）」，不会把它误称为手工上传原文件。
4. 每次导入都有批次 ID。生成快照时保存批次、稳定指标标识、提取规则、源文件关联、清洗结果及规则匹配的行序号。同名指标按规则标识区分。比率指标的匹配表保留分母范围，计数指标只保留匹配计数条件的记录。
5. 原始表和提取数据不随 SLA 快照列表的 50 份保留上限、删除快照、清空浏览器缓存或清空上传历史自动删除。历史导入中没有存储过的原文件无法补回；旧指标仍可引用，并显示原文件缺失说明。

存储都位于当前租户的 tools.db：`import_source_batches`、`import_source_files`（含原始文件 BLOB）、`import_source_sheets`、`import_source_snapshots`、`monthly_documents`。使用现有租户数据库连接，无新增 JSON 数据库。全租户数据库备份包含这些表；原有报表专项导出包尚未扩展到原始资料库，迁移资料库请使用全租户备份。

## 独立月报设计

资料库默认按浏览月份展示各业务来源的最新版本；同一来源的其他版本放在条目详情中。「历史版本 / 高级筛选」保留月份、导入日期、批次浏览。显示名称优先使用该表关联的提取指标名；有多个指标时并列显示，没有指标时使用原文件名。详情仍显示完整原文件名，下载保留原文件字节。旧上传接口产生的 UTF-8/Latin-1 文件名乱码在读取时兼容纠正，并恢复同批次的指标关联；不批量改写历史库或原始文件。旧工程的文件系列标识保留别名兼容。

历史看板「载入到当前页面」使用同一文件名修复接口。旧浏览器回顾缓存恢复时，会按文件 ID 和工作表标识从当前租户资料库修复标签标题、来源文件名及缓存名称；不改写缓存行数据、不重复上传、不生成新快照。离线时保留已有缓存行，下次联网刷新再尝试修复名称。

导入提取快照与报表保存的考核结果是同一次导入的两种口径，并非给新、旧月报分别使用。资料库合并相同导入/目标月份组合；不同考核月份仍分开。模块中「固定快照」只列出当前指标口径的相关记录，清洗模块不重复列出报表考核记录。选项显示导入时间、目标月份、提取/考核口径，隐藏内部 ID；可进一步按目标月份及导入日期筛选。资料库筛选仅改变浏览列表，不改写已绑定模块，也不改变「自动引用」的最新匹配语义。

数据导入页「历史看板」中，有对应原始存档的快照会在删除按钮旁显示「载入到当前页面」。它从当前租户的原始资料库读取该批次的全部文件及全部工作表，恢复快照的导入分组（整改、常规、专项、SR、漏洞及其他指标表），合并参与该快照的首张工作表；附加工作表和该批次未参与快照的文件保留为回顾标签；不应用目标月份筛选、不重复上传、不生成新快照、不改写历史得分。原表解析状态为未完成/失败时，可尝试下载原文件在浏览器重新解析。载入前先读取所有表格，读取失败不替换当前工作区。监控按当前规则和日期执行，指标优先使用当前配置，配置不存在时恢复快照保存的指标规则，并同步恢复指标高亮、核心数据舱和目标月份选择。附加回顾标签不参与跨表指标统计。旧回顾缓存联网后自动重新载入以恢复监控。没有原始存档的旧记录不显示此按钮。

初始版式参考上传的「护网与网络安全月报」HTML：总标题、Logo、报告信息、整体情况、网络变更、SR、风险治理、License、EOS、第三方软件、内控与例会等九个模块。该编辑器使用自己的文档模型，不调用旧月报的 summary、ranking、matrix 或趋势模板。

- 直接点击编辑总标题、副标题、模块标题、内容标题、正文和页脚。中英文分别保存。
- 「页面与信息栏」可修改文档名称、页面宽度、Logo 位置/宽度、信息项标题与值，增删信息项、调顺序和宽度。
- 模块可增删、上下移动，设置网格宽度；每个模块可插入多个内容位置，每个位置可调整宽度、顺序、对齐，或移至另一模块。窄屏自动变为单列。
- 内容类型：文字、提取指标、原始/清洗表、图表、规则总结。通过「绑定与布局」直接引用 SLA 快照提取指标、报表已入库考核指标（保留当时实测与目标），或任何已存原始表，包括无规则表。可选工作表、展示列和行数，并添加/删除筛选条件。界面提供可用字段勾选和字段名提示。
- 旧版「自动引用最后一次导入」保留同一规则标识/原文件系列的全库最新语义；新引用推荐使用右侧「对应月份最新版本」。检查并应用月报数据更新后引用新记录；「固定历史快照/文件」保持指定来源。最新相关模块已移除指标时显示无数据，避免默默引用旧值。
- 原始表未经清洗；指标的清洗表引用当时提取规则匹配的记录，不用当前规则重算。图表支持指标历史值或原表按列计数/求和，最多展示最后 40 组；明细表最多展示设置的行数，页面会说明完整记录数与实际展示数。
- 总结规则是每个独立总结块的中英文句式。字段：`{label}`、`{value}`、`{date}`、`{target}`、`{gap}`、`{count}`/`{rows}`。规则随模块增删改，无需 AI。
- 管理员「保存到服务器」可保存多份月报；所有登录用户可查看、编辑当前页面和导出。工程导入不直接覆盖服务器文档，引用按当前租户解析。HTML 导出包含当前数据与图表，去掉编辑控件；平台 Logo 嵌入文件。PDF 通过系统打印生成。

## API

API 使用现有 `/api/upload` 鉴权、租户及管理员写入限制。原文件下载也需要登录，跨租户 ID 返回不存在。

- `POST /api/upload/source-batches`
- `GET /api/upload/import-settings`、`PUT /api/upload/import-settings`（`uploadOriginals` 布尔值）
- `POST /api/upload/source-batches/:id/files`（multipart，file 字段）
- `PUT /api/upload/source-files/:id/sheets`
- `GET /api/upload/source-catalog`
- `GET /api/upload/source-files/:id/download`
- `GET /api/upload/source-sheets/:id`
- `GET /api/upload/source-snapshots/:id/sections/:key`
- `GET /api/upload/source-snapshots/:id/metrics/:key/rows`
- `GET /api/upload/monthly-documents`、`GET /api/upload/monthly-documents/:id`
- `POST /api/upload/monthly-documents`

## 分类 / 系列图与通用数据透视

图表配置提供六种展示类型：纵向柱状图、横向柱状图、折线图、面积图、饼图、环形图。切换类型保留原表绑定、数值列、客户筛选和图例；新式多表绑定默认纵向柱状图，历史单数据绑定保留原横向柱状图样式。笛卡尔图使用相同的系列配色和可选数值轴压缩，面积图使用渐淡填充；折线与面积遇到缺失值会断开，零值仍保留。饼图 / 环形图通过「展示系列」单独选择月份，显示客户数值和占比，环形中心显示合计；全零或含负数的所选系列显示对应提示。图表类型和系列选择随月报 / 工程保存，HTML / 图片 / 单页 PDF / 打印沿用同一 SVG。

类型验证：`node_modules/.bin/electron tests/monthly-designer-chart-types-browser.cjs` 覆盖六种类型切换、数据绑定保持、缺失点 / 零值、月份占比、负数提示、历史单表、保存重载和 HTML / PNG / 单页 PDF 导出。

在模块内添加「数据图表」，展开左侧某个原始表，将工作表名拖入图表的「添加月份系列」区域（也可用下拉选择）。默认识别客户列和首个数值列，从文件名识别月份；可分别调整各系列的横轴、数值列和图例。不同表按客户名称匹配，重复客户的数值求和，缺失数据留空、真实零值保留，默认排除总计 / 合计行。

左侧资料库仅提供源表选择及表名按钮；字段选择、拖放与分类筛选统一在右侧透视面板操作。历史系列图的类别 / 数值列仍可通过其配置下拉调整。支持最多 8 个系列、40 个客户；旧系列保留其原有指定工作表行为，新引用提供相对月份与版本规则，删除其他自定义 HTML 工具不会影响功能。

首尾系列的变化同时达到百分比和绝对差值阈值时，显示带尖头的曲线箭头；默认阈值为 20% 和 5，可自行调整。配置随月报 / 工程保存。HTML、PNG、单页 PDF 与打印输出保留 SVG 图表、图例和箭头，隐藏拖放和配置控件。

验证：`node_modules/.bin/electron tests/monthly-designer-charts-browser.cjs` 使用临时数据库验证系列配置、客户匹配、零值、合计排除、箭头阈值、行列拖放、保存重载，以及 HTML / PNG / 单页 PDF 导出。

曲线箭头使用柱顶附近的短渐变带状标记，长度不随两个柱子的高度差增加。纵轴默认在非零数值最大 / 最小比达到 8 时自动采用平方根压缩，刻度及柱顶标签仍显示原值，图上注明压缩方式；可切换为线性比例或固定平方根压缩。设置随文档保存，并同步用于所有导出格式。

模块和内容卡片的工具栏提供「⧉ 复制」按钮，副本紧接原位置插入，保留中英文内容、文字格式、宽高、筛选和数据 / 图表配置。副本及所含卡片使用独立 ID，可独立编辑、撤销，并短暂高亮。验证：`node_modules/.bin/electron tests/monthly-designer-copy-browser.cjs`。

左侧资料库偏好随每份月报保存：浏览月份、导入日期、批次、搜索词、常用收藏、最近使用、来源类型、业务分类及原始表展开状态。载入月报或工程时恢复对应配置，切换月份后保存仍使用月份后缀并保留其他月份月报。新建月报及没有偏好配置的历史月报默认选择资料库中最新的目标月份，再选择该月份最近的导入日期；较新导入的旧月份值班表不会改变默认目标月份。保存的来源已经不存在时，选择可用的最新月份 / 日期 / 批次。验证：`node_modules/.bin/electron tests/monthly-designer-library-browser.cjs`。

所有卡片使用右侧「组件配置」面板。历史系列图与透视图的设置均不占卡片高度；⊞ 打开数据处理，绑定、映射与数字格式快捷按钮打开对应设置。隐藏设置不会改变 SVG 尺寸或卡片最小高度；HTML / PNG / PDF / MSG 始终移除配置控件。

在图表配置中点击「通用透视配置」可将已有系列转换为透视配置，保留已存档来源、分类 / 数值列映射和筛选。支持最多 8 个源表，按同名字段追加记录，异名字段可逐表映射；「来源表 / 月份」是内置分组字段，来源标签可编辑。行 / 分类轴、列 / 图例支持多个任意字段，支持字段前移、移除、交换行列，以及从右侧字段列表拖入四个区域。值区最多 8 个字段，支持求和、非空计数、数值计数、平均值、最小值、最大值、去重计数；内置记录数字段统计每条记录。筛选支持等于、不等于、包含、数值比较、空值 / 非空，以及多选包含 / 排除，多个条件以 AND 合并。可按分类或聚合值排序。

透视结果可切换六种图表或「透视表」，选择显示行 / 列总计。平均值和去重计数的总计基于原始记录重新计算，避免把各单元格的平均值或去重人数相加。图表最多展示前 40 个分类 / 8 个系列，透视表最多展示前 200 个分类 / 64 个结果列；编辑页来源说明显示展示数量与实际数量。透视配置随月报 / 工程保存。透视实现保留归档数据，不写回源表，也不引入额外存储。

导出时将 Logo（包括包含嵌入图片的 SVG）用浏览器光栅化为内嵌 PNG，解决 html2canvas 未绘制 SVG 内部图片导致的 PDF / 图片 Logo 空白。移除工具与配置栏后，重新测量清洁布局，使编辑页同排、同高度的卡片保持一致；编辑页原本不同高度的卡片继续保留自身布局。卡片实际 padding 会带入导出，避免 iframe 响应式断点改变内容尺寸。

### 数据规整（显示格式）

组件顶部 `0.0%` 打开右侧数据规整编辑区。规则支持指定原始列名、原始行名（可选择行名称所在列），或全部数值；名称可从当前源表中下拉选择，也可手动填写。每条规则可设置数字、小数乘 100 显示为百分比、原值直接加百分号，支持 0–8 位小数、千分位及零值留空。已有 `%` / `％` 的输入不会再次乘 100，非数值和空值不会被转换。行规则优先于列规则，列规则优先于全部数值；自动范围不格式化分类名称，明确指定分类列时才格式化它。

规整仅改变显示，原始表、筛选、透视求和/平均等计算保留源值和完整精度；表格和图表渲染保留数值元信息，使规整不依赖此前已经四舍五入的文字。支持原始 / 清洗表格、透视表、指标和图表数值标签；单一数值字段的图表坐标轴沿用该列格式，多字段坐标轴只采用全部数值规则。可以同时使用名称映射，规则依然匹配原始名称。HTML/PDF/图片导出复用显示结果。

规则在组件 `dataFormats` 中随月报保存；顶部报告月份切换后继续保留。窗口中的“保存复用配置到服务器”写入当前租户 SQLite 的 `monthly_data_format_presets`，与名称映射复用配置分开保存，没有月份限制。其他月份或新建月报可载入、修改、删除，历史月报保留自己的配置副本。新增 API：`GET/POST /api/upload/monthly-data-format-presets`，`PUT/DELETE /api/upload/monthly-data-format-presets/:id`，沿用平台鉴权及管理员写操作限制。名称映射与数据规整共用 `preset-editor.js` 窗口流程和后端预设持久化逻辑。

## 月报工作区与数据引用规则（2026-10）

顶部「报告月份」是月报的正式月份入口。左侧「浏览数据月份」仅筛选资料库，可查看历史来源，保存资料库习惯不会覆盖报告月份。修改报告月份先显示更新预览，取消不修改报告。新月报按模板规则匹配来源；改变月份保存时生成对应月份的报告，保留旧月报。

左侧提供常用、最近使用、全部，以及来源类型与业务分类筛选。版本按来源类型和稳定来源标识分组，不仅凭显示名称合并。工作表按钮可拖动，数据预览只读取选中工作表并显示前 100 条；历史版本工作表按钮在展开时生成。勾选多表只表示选择，点击操作栏才使用；无选中组件时不能「加入当前组件」。拖到正文替换表格，拖到分类空白新增表格，拖到图表数据源区追加来源；替换和更新支持撤销。

数据来源页签分开配置：月份关系（本月、上月、去年同月、偏移月份、固定月份、全库不限月份）和版本选择（对应月份最新、固定指定版本），并显示本次实际月份、导入时间和工作表。新引用不在缺少数据时借用其他月份；缺少可识别月份的静态来源默认固定所选版本。旧绑定显示「旧版引用」，保持原标识和版本语义，用户可主动采用新规则。

「刷新资料库」只发现新数据。「检查月报数据更新」列出各组件当前和候选来源，检查所需字段，支持应用选中或选择全部更新；缺少来源 / 字段不应用。同一份预览共用读取结果和稳定版本选择，最多并发检查 4 个组件；可取消，失败组件不阻塞其他组件。报告月份切换时要求应用可匹配的月份引用组件；失败组件明确显示保留结果。

新引用默认保存本次来源元数据和输入结果到报告自身，重新打开时恢复该结果，即使来源被移除仍可预览和导出，并在右侧提示来源不可用。可明确选择「自动跟随来源规则（高级）」。旧报告没有被迁移改写；旧引用的行为保留。每个保存结果限 12 MB，月报负载限 40 MB；大数据来源可选择自动跟随方式，原始资料库数据不被裁剪或重写。新模板的动态指标按正式报告月份匹配，正文 / 信息栏指标也参与更新预览、应用与撤销；字段配置失效时保留上次成功的结构化结果并支持保存重载。手填内容在跨月预览中提示核对。

数据处理仍使用现有透视算法：多表按字段追加记录，异名字段逐表对应；字段对应影响计算，显示名称和数字格式只影响展示。图表类型共享同一份透视输入和配置，可切换表格、纵向 / 横向柱状、折线、面积、饼图、环形图。考勤、专题和值班来源保留既有日期筛选逻辑；考勤表来源说明显示窗口、原始 / 适用行数及无法识别日期数量。

右侧「组件复用配置」保存完整单组件的来源规则、布局、透视、样式、显示名称和数字格式，主动载入后才应用。它与保存月报、设为默认模板分开，不覆盖历史报告；模板与复用配置排除业务行和历史预览结果。当前租户 SQLite 新表为 `monthly_component_presets`；API 为 `GET/POST /api/upload/monthly-component-presets`、`PUT/DELETE /api/upload/monthly-component-presets/:id`，沿用鉴权、管理员写限制及租户连接。

验证：`node --test tests/monthly-source-rules.test.js tests/monthly-component-presets.test.js`；`node_modules/.bin/electron tests/monthly-workspace-redesign-browser.cjs`，覆盖月份分离、暂存选择、右侧布局 / 映射、来源规则、资料库刷新隔离、更新预览 / 应用 / 撤销、保存结果、来源删除后重载、跨月匹配及未勾选字段拖放。

### 资料库近期加载与诊断

左侧默认加载最近90天的目录，支持输入0–36500天，0或「全部」加载完整历史。按原文件存档时间、提取 / 考核快照时间、专题导入时间及考勤快照保存时间筛选，不按表内的业务日期裁剪数据。`GET /api/upload/source-catalog?days=N` 在读取数据库时限制范围，旧调用不带参数仍返回完整目录。目录附带不含数据行的 `diagnostics` 阶段数量与耗时。

加载天数保存到 `libraryPrefs.loadDays`，同时记住本浏览器习惯。月报引用索引与左侧目录分开，必要时加载历史索引；这不会扩大左侧显示范围，也不会清除已保存结果。检查月报更新仍使用完整来源索引。

底部日志显示请求路径、HTTP状态、请求ID、等待耗时、原表 / 提取 / 考核 / 专题 / 考勤阶段数量。成功4秒后隐藏，失败保留，支持复制和重试；「更多 → 加载日志」可重新打开。日志仅存在于当前页面内存，不记录 Cookie、授权头或数据行，不进入导出。

顶部「导出」及「更多」收纳次要操作；左侧提供全部 / 常用 / 最近使用选项卡，折叠来源详情与类型 / 分类筛选，隐藏空分类。「预览」隐藏正文控件并禁用编辑，点击「继续编辑」恢复。完整体验审查及后续优先级见 [monthly-workspace-ux-review.md](monthly-workspace-ux-review.md)。

验证：`node --test tests/monthly-library-catalog.test.js tests/monthly-request-client.test.js`；工作区浏览器回归补充天数修改、完整历史、月份保护、日志成功自动隐藏 / 失败保留 / 重试及预览切换。

资料库展开区采用统一的工作表列表：勾选用于暂存选择，拖动表名插入月报，预览按钮查看数据。下载入口使用统一按钮，多文件展开显示完整文件名；历史版本和来源详情位于次级折叠区。工作表名称过长时省略显示，完整名称可通过悬停查看；样式兼容暗色主题和窄屏。

右侧组件配置采用全高面板：固定标题、四个页签和底部状态区，中间配置内容独立滚动。来源、处理、展示样式和布局使用统一字体、控件尺寸与月报深蓝配色。名称映射、数字格式在侧栏以纵向规则卡片呈现，保留服务器复用配置功能；窄屏面板位于月报下方。

桌面资料库与月报间距12px。1900px及以上宽屏采用左右对称留位，使月报居中，资料库与组件配置随可用空间扩展至600px；中等屏幕资料库为360px。打开或关闭组件配置不再改变资料库、月报的位置与宽度；右侧面板使用剩余空白区域，空间不足时移到月报下方。

组件布局使用独立轻量表单，仅编辑所属模块、网格宽高和对齐，不生成指标/来源版本下拉框，也不读取工作表。布局应用保留数据绑定、透视规则和保存结果，支持撤销；内容类型仍可在高级绑定入口调整。

资料库与组件配置采用相同的浅色/暗色配色、面板圆角、字段和按钮尺寸、页签选中态。资料库标题固定，加载范围、筛选与数据目录在内部独立滚动，数据条目使用卡片分组；现有居中布局和面板宽度规则保持不变。

两侧折叠区使用带背景的标题按钮与旋转箭头区分开合状态，展开内容有轻微淡入过渡。保留原生details/summary键盘操作，并遵循系统减少动态效果设置。

预览模式隐藏左侧资料库，月报居中显示；返回编辑恢复侧栏。原始表历史版本列表排除当前卡片已展示的原文件（含合并成员），没有其他版本时显示空状态。


原始表预览使用接近窗口大小的独立数据工作台，11px 表格字体，支持全部记录分页（每页100/200/500/1000）、全列查找、按列包含筛选、表头排序及双击单元格编辑。替换与表头规则支持按列或全列精确/包含值替换、表头重命名，规则按顺序执行并可增删改。试应用只修改弹窗草稿；保存前列出变更数量，二次确认后写入当前租户的解析表。并发修改会拒绝覆盖并要求重新打开。

勾选“保存规则”后，服务器按归一化原表类型保存规则（去掉自动抓取前缀、Latest及日期）；后续同类型原文件的工作表解析入库时自动应用。删除全部规则并保存可停止自动替换。历史报表快照、已经保存的提取结果和上传文件字节不重算或重写；原始表回看及使用当前解析表的月报刷新会读取修改结果。专题、会议考勤等业务快照提供只读查找/筛选/排序。规则保存在 SQLite `source_table_rules`，跨月复用且租户隔离。

组件复用配置保存当前单个组件已应用的来源、处理、展示和布局整套设置，不按页签分别存储，也不修改默认模板。默认模板负责整份月报生成；复用配置用于在其他月报或模板中主动采用单个组件的成熟设置。入口在组件配置底部，点击后在按钮下方独立展开，保留上方设置及未应用输入，再次点击可收起。

原始表工作台有保存规则时默认展开，并在入口显示规则数量；编辑接口禁止浏览器缓存。旧档案中 Latin-1 解码的中文来源标识在读取时兼容归一化，既有规则无需重建即可供正常编码的后续导入复用。顶部月份控件使用与操作按钮一致的字体、高度、圆角；年份和十二月面板支持键盘导航、Escape关闭及选择本月，选定后仍进入数据更新预览。

编辑原始表替换规则后，点击「检查并保存」会先应用修改后的规则到当前工作表，再展示表头和单元格变更数量，确认后写入服务器。历史仅保存而未应用的表头映射在打开预览时自动呈现，检查并确认保存后写入当前表；仅查看预览不改写服务器。重新打开预览不自动重复执行单元格值替换。服务器确认保存规则时也会补应用遗漏的表头映射，避免旧客户端只保存规则而未更新当前表。

组件顶部快捷按钮按「数据来源、数据处理、展示样式、布局」排列，与右侧配置四个页签使用同名和同款线条图标，点击直接进入对应页签。名称映射和数字格式继续在展示样式中配置；移动、复制与删除位于操作栏右侧。

英文模式统一采用月报术语和服务器指标名映射：已配置映射优先于内置术语，未知业务名称保留原文，不自动猜译。已知旧默认标题误译（例如 License 管理误写 Risk governance）在显示时校正；用户自定义英文文案保留。透视四区、跨表字段映射、显示名称、数字格式均翻译显示标签，字段绑定和数据计算仍使用原名。

「选择指标 / 清洗结果 / 高级绑定」直接切换到数据处理页签，来源页不再追加完整表单。图表的数据处理页保留可展开的指标绑定区，展开时才加载表单；尺寸、位置和对齐继续由布局页管理。

资料库分为原始表与指标、专题、会议考勤三路请求，逐路显示已完成目录。目录请求最多等待60秒，失败来源保留上一版目录并可单独重试；读取表数据仍按15秒超时，最多并行4路，不包含保存请求。组件独立重试不会重绘或重新读取其他组件。

会议考勤默认只读取按导入/更新时间选出的最新快照的完整内容，沿用原有按报告月份和会议窗口筛选规则；“历史版本 / 高级筛选”可显式载入历史。旧月报保存的数据及具体快照引用继续有效；自动补充索引时只额外读取明确引用的旧考勤快照，不遍历全部历史考勤。目录跳过损坏记录时保留诊断代码和来源ID，不记录表格正文或鉴权信息。

保存或导出遇到仍在读取的组件时，提供继续等待、取消本次操作，以及有历史结果时“停止读取，使用保存结果”。多表组件不会在部分来源失败时使用残缺数据计算。默认模板读取失败或格式不兼容时显示提示并打开基础模板，不覆盖服务器模板。

## 可编辑文本中的动态指标

正文、各类型组件标题、模块标题、报告标题、信息栏标签与值、页脚均可输入 `@` 搜索引用指标；数据处理中的中英文总结规则也支持此入口。源表单元格及统一管理的报告月份保持只读，仅可调整展示格式。

单击指标会选中整个引用并显示文字工具条，支持字号、文字颜色、粗体、下划线、背景色及对齐。指标默认继承上下文样式，不使用固定底色或额外内边距；背景色选择“无”只清除当前选区的底色，不改动相邻文本。引用作为完整单元保存，部分选择显示数字时也不会拆开引用标记。

双击指标可重新打开选择器，恢复原有来源、主/子指标与分类；更换引用时保留文字格式和所在位置，取消不改变引用。保存、工程重载及导出保留文字样式，导出使用已解析数值并去掉编辑属性。资料库刷新与报告数据更新仍保持各自原有职责。

选中同一可编辑文本区内连续的两个指标（中间允许空格），文字工具条自动显示「已选中2项 · 公式计算」。公式用 A、B 对应两个引用，支持四则运算、括号、乘方，以及 ROUND、MIN、MAX、ABS；提供相加、相减、相乘、比例、平均值、变化率快捷选项和即时预览。仅支持两个指标，不支持第三个变量或嵌套引用其他公式。非数值、除零或非法公式不能应用。

无需精准拖选：单击一个指标，文字工具条显示「与相邻指标计算」，优先选择紧随其后的指标，没有适用的后项时选择前项；不会跨过正文、换行或其他公式。也可单击第一个指标，再按住 Shift 点击相邻指标一起选中。鼠标拖选结束时保留已有选区，不再被指标单击行为缩回一个指标。

应用后正文只显示计算结果，可设置最多0～6位小数或百分比，并继续使用文字样式工具条。单击结果打开公式编辑；「取消公式，恢复两个指标」恢复原引用及各自原有文字样式。复制组件后修改公式只影响该处结果，支持撤销。公式保存指标标识和表达式，不冻结为手填数字；检查并应用月报数据更新后重新计算，单纯刷新资料库或修改表达式仍使用当前月报保存的指标值。公式随月报、工程、模板及组件复用配置保存，导出 HTML、图片和单页 PDF 仅显示解析后的结果。

数据资料库外层及内容区始终隐藏滚动条，保留鼠标滚轮、触控板和键盘滚动，不通过禁止滚动隐藏内容。

## 首屏加载与平滑展示

编辑器 HTML 首屏自带毛玻璃加载层，平台全局菜单栏始终可见且可访问；加载层从全局菜单栏下沿开始，隐藏未完成的编辑器工具栏、资料库及月报结构，准备完成后再平滑显示。羽毛采用细羽枝矢量图形及轻摆动画，不额外下载图片。进度按8个真实完成或失败的步骤计算：月报列表、月报/模板、三类资料库、引用解析、组件渲染、字体及 Logo；不会随时间自动增加。部分来源失败仍显示可用数据，详情区标记未能加载的步骤。

组件完成渲染后，字体及 Logo 最多额外等待5秒，随后平滑显示编辑器；资源未能完成时在步骤详情中标记。启动阶段可停止等待，终止读取并进入编辑器；月报载入失败显示重新加载与进入编辑器入口，失败不伪装为全部完成。首屏结束后的资料库刷新继续使用原加载日志，不重新遮挡整页。中英文、暗色、窄屏和系统减少动态效果均适配，所有导出均排除加载界面。

### 月报页面入口

平台“月报页面”（`/monthly`）直接打开通用月报编辑器。编辑器顶部的“旧月报”按钮打开 `/monthly/legacy`；原页面 `/pages/monthly.html` 仍可访问。中英文切换会同步更新编辑器名称、浏览器标题与旧月报按钮。

### 指标复制粘贴

月报可编辑文字区复制/剪切包含指标或公式的选区，会同时携带引用、公式定义及文字样式。粘贴到编辑器其他文字区或另一份月报时恢复可编辑引用，并按目标月报数据解析；每次粘贴公式创建独立定义。撤销可恢复粘贴或剪切前状态。粘贴到外部软件或选择“粘贴为纯文本”只保留显示数值。外部任意 HTML 不作为编辑器代码执行，只有通过校验的编辑器剪贴板元数据才恢复引用。原始表只读单元格仍不允许粘贴修改数据。

### MSG 邮件布局

MSG 正文保留原页面导出宽度，不自动撑满邮件窗口；Logo 与模块标题通过原生邮件表格明确对齐，避免失去 Flex 后左移或竖排。不附加页面中没有的说明文字。文字、指标显示值与数据表格保留 HTML 文本，可在支持邮件草稿编辑的客户端编辑；Logo 和图表通过 CID 图片呈现，图表不能在邮件中修改原始图形数据。邮件客户端渲染能力不同，浏览器预览和 MSG 结构校验不等同于 WPS/Outlook 实机验收，不能保证所有客户端像素级一致。

邮件正文中显示的文本换行转为显式 `<br>`，不依赖客户端支持 `white-space: pre-wrap`。快捷跳转使用同封邮件中的短名称书签（`mr_section_N`），链接只包含 `#书签名`，不包含平台页面地址；客户端若不支持邮件内部书签，仍需在该客户端验证，导出不会将其改成外部链接。

页面四周双线在邮件中通过两层原生表格单元格边框呈现，沿用页面边框颜色，中间保留间隙，不依赖客户端支持 CSS `border-style: double`。

### 指标引用检查

组件工具栏的「引用」按钮只检查当前组件。普通引用气泡显示指标名称和实际快照时间；双指标计算气泡显示代入数值后的简洁公式，下方小字显示 A、B 的指标名称和快照时间。气泡自动避让并用连线指向数值，重叠的横向连线按 8px 间距错开；数值、连线和气泡以同组柔和浅色对应区分。再次点击同一组件按钮或按 Escape 收起，点击另一组件按钮切换检查范围。检查信息不写入月报，不进入预览、打印或导出。

### 切换已保存月报
顶部选择已保存月报后自动载入，不再需要载入按钮。有未保存修改时显示保存提示，支持保存并切换、不保存切换、取消或 Escape；保存失败不会切换，读取失败保留当前月报。报告月份和左侧浏览数据月份仍分别管理。

### 删除服务器月报
更多 → 删除月报支持搜索、单选、多选和全选搜索结果。确认删除前列出所选月报，管理员确认后才从当前租户删除。默认模板、资料库和复用配置不受影响；删除当前月报时保留页面内容为未保存草稿，再次保存会生成新月报。删除不能撤销。

页面右下角显示实际执行的主脚本版本（例如 `脚本 v20261011-52`），预览及导出不包含版本标识。发布编辑器修改时同步更新 designer.js 内的 scriptVersion 和页面缓存版本。
