# AI 月报提示词优先级与展示约束

适用于大平台 AI 月报及已安装 AiOps-Report 的浏览器 ADC 月报后端。

## 优先级

1. 真实数据、权限、只读 SQL、沙箱与响应协议是技术边界，不受展示要求覆盖。
2. 当前格子经用户确认的最新展示要求及局部例外，优先于章节与整体风格的默认展示要求。
3. 章节样式优先于整体风格默认值；未涉及修改的规则继续保留。
4. 隐藏提示词里的排版、总结长度、旧配方只是默认值或参考，不得恢复被用户删除的组件。

## 本次修复

- 最终提示词保留旧指标卡而对话承诺仅文字：汇总阶段校验并重试，不能带着已发现的冲突继续编译。
- 纯文字要求随旧配方恢复卡片：在提示词中记录格子展示约束，编译及运行时统一应用；只替换 render/narrative，不改配方的 sources/compute。
- 一句总结变成多句：中英文总结校验句数，不合要求时重写；不截断半句。
- 格式被锁死：允许用户恢复指标卡、图表或表格；手动编辑的新提示词也参与时间顺序判断。
- 章节统一样式重新改变格子内容：保留格子的明确组件类型与局部例外；允许按明确的位置要求迁移 narrative/render 中的总结，避免“原来为 null 必须永远为 null”的限制。
- 固定 3–10 句指令、默认总结长度、总览必须 narrative 等隐藏要求：改为默认，用户明确要求优先。
- 窄格子无条件纵向堆叠：明确要求左右并排时，不追加相反的隐藏指令，CSS 不强制堆叠；实际放不下时仍由布局检查报错、压缩或回退。

自然语言并非所有形式都能机械识别。当前程序校验重点是明确的中文“仅文字/只保留一句”等要求和已记录的展示约束；其它复杂要求仍由模型处理，不能把成功运行等同于所有语义均已验证。遇到争议应查看调用记录中的最终提示词、模型回复及配方。

没有重写运行中的历史月报、整体风格或数据库快照。已有错误格子需重新生成最终提示词并运行；纯前端改动需刷新页面，大平台路由改动需随后端发布或重启加载。
