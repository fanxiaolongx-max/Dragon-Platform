# 译维仓储管理检查与使用说明

## 迁移和主题入口

顶部右侧固定显示“迁移旧数据”和主题选择框；主题可选“浅色 / 暗色 / 跟随系统”。主题选择只保存浏览器界面偏好，不存储业务数据，也不会触发仓储数据保存。

“迁移旧数据”会说明是否检测到当前地址下的 `ezscan_local_full_v3`。未检测到时仍保留入口，可选 JSON 文件或粘贴完整备份。不同浏览器、localhost、127.0.0.1、内网 IP、端口、本地 HTML 文件各有独立存储空间，页面无法跨来源自动读取它们；需要回到旧地址导出 JSON。

迁移、恢复需要管理员和明确确认，会先下载当前数据备份，再按服务器版本保存；旧浏览器数据保留。并发版本或租户变化会拒绝覆盖。

## 检查范围

覆盖首页、业务流程图及 26 个业务页面，共 28 页；对所有 14 类单据检查提交、审核、生效和反审核。

| 功能 | 行为及校验 |
| --- | --- |
| 首页、流程图 | 实际服务器数据、库存预警、账款余额、待审核入口、按货品及单位分开的图表 |
| 库存、出入明细、月度统计 | 仅已审核单据影响库存；调拨出入对应；月报按月、仓库、货品分组并保留单位；可追溯源单和下钻 |
| 货品、仓库、往来单位 | 唯一编码、引用删除保护、仓库启停；已有业务货品不允许修改计量单位；采购和销售校验往来单位类型 |
| 采购、销售订单和执行单 | 订单不改库存；已审核订单生成一张执行单；执行单绑定来源单位；禁止重复执行及超出订单货品、数量 |
| 入库、出库、调拨、转换 | 审核校验正数和库存；负库存拦截；反审核时检查后续库存消耗、执行单及关联收付款 |
| 盘点 | 按审核时账面库存冻结差额；校验货品、仓库和差额一致性；切换草稿仓库需要重新录入实盘数 |
| 条码、序列号、CSV | Code 39 编码与预览；数量变化清除失效序列号；CSV 缺省单价、重复表头、总行数和异步单据变更保护 |
| PDA 记录 | 手工/浏览器采集、仓库筛选、状态确认；记录本身不改变库存 |
| 应收、应付 | 自动账单与审核源单绑定；金额精确到分；分次收付款、撤销、超额校验；收付款合计与已核销额一致；展示逾期状态 |
| 审批流程、岗位角色 | 维护和预览模板；实际访问由平台账号控制，管理员可写、其他账号只读 |
| 备份、测试数据、标签管理 | 独立 SQLite 快照、JSON 恢复、冲突导出、追加/清理测试数据、固定和最近标签、无写入的只读导航 |

## 测试数据

“数据备份 → 追加测试数据”追加一组 `sampleTag=ezscan-sample-v1` 的记录，不覆盖原有数据。重复添加不重复创建。

一组包含 6 个货品、3 个仓库（含停用仓）、3 个往来单位、42 张单据（14 类型 × 3 状态）、12 条期初库存、3 条扫码记录、3 条关联自动账单、6 条独立账款，以及审批和岗位模板。包括零库存、低库存、逾期、部分核销和结清示例。

测试档案名称含 `[测试]`，页面有测试提示。“清理测试数据”仅删除带此标记的记录；正式业务已引用测试货品、仓库或单位时拒绝清理，避免留下孤立数据。

## 当前能力边界

- PDA 页面支持浏览器采集和记录管理；没有连接真实手持设备协议。
- 审批流程是模板，单据实际采用“草稿 → 已提交 → 已审核”的固定流转；没有按模板执行的多人审批引擎。
- 岗位角色是业务模板，不能替代平台账号权限；没有按仓库分配的细粒度岗位授权。
- 采购/销售订单当前采用一张执行单；不支持分批收发、批次成本或序列号全生命周期追踪。

## 主题细节检查

`frontend/css/ezscan-warehouse.css` 统一定义两种主题的文字、背景、边框、悬停、选中、焦点及禁用颜色。禁用项使用专用配色和鼠标状态，不再通过整体透明度使文字变淡。

颜色回归测试覆盖全部 28 页、档案详情与编辑、草稿和审核单据、全部标签搜索及空结果、标签设置、右键菜单、货品选择、资金核销、期初库存、条码预览、迁移和备份弹窗、错误提示、只读状态、桌面和窄屏，以及横向/纵向滚动后可见的区域。包含当前项、悬停、输入焦点和禁用按钮。

当前两种主题共检查 346 个页面/交互/滚动状态、35,862 次可见文字及占位文字测量，未发现低于阈值的情况。普通文字至少 4.5:1，大号文字至少 3:1；禁用文字也按相同标准检查。测量排除不可见内容和装饰性版本水印，并对弹窗合成后的实际背景、透明度进行计算。截图与 JSON 报告由测试输出到临时目录，供复核。

## 保存确认与网络恢复（2026-10-17）

原审核提示在 450 ms 延迟保存前就显示“已更新（尚未保存至服务器）”，且保存完成后不会更新该提示。一次失败也会停止后续自动保存，直到手动重试。

提交、审核、撤回、反审核及显式保存现在等待服务器确认；等待期间禁止重复业务操作，成功后才提示“已保存到服务器”。草稿输入仍自动保存，保存类提示随确认结果更新，校验和导航提示不再被误加保存后缀。

网络、超时、5xx 等临时故障会在 0.8 秒和 2 秒后最多重试两次；重试前读取服务器版本和数据。如果请求已经落库但确认响应丢失，会核对相同租户、下一版本和完整数据，确认后继续保存后续修改，避免重复写入。若其他窗口已修改数据或租户变化，则保留待保存修改并阻止覆盖。权限和数据校验错误不自动重试。

恢复网络或继续编辑时会重新尝试待保存数据；重试用尽仍明确显示失败，提供“重试保存”和“导出未保存修改”。切出页面触发刷新保存队列；关闭页面时仍有待保存修改会提示。持续断网时不能宣称服务器已保存，应保持页面打开，恢复网络后等待确认，或先导出未保存修改。

回归测试新增真实点击下的延迟审核确认、无手动 flush 的草稿自动保存、连续失败与 online 恢复；同时测试响应丢失后回读、后续输入合并、并发和租户变化保护、永久错误停止重试。全部测试使用临时数据库，不修改现有仓储业务记录。
