# Dragon 2D 桌宠

以用户提供的青绿色毛毡小龙照片为参考，使用 imagegen 生成手绘风格透明素材。最终采用 2D；已移除试验性的 WebGL 模型和旧图特图片。

四张 1536 × 1024 透明图集，每张四列两行，共 32 张姿态：

| 图集 | 内容 |
| --- | --- |
| idle-atlas.png | 睁眼、半闭眼、闭眼、重新睁眼，以及四种张望姿态 |
| wave-atlas.png | 抬手、挥手、放下的八个连续姿态 |
| walk-atlas.png | 八个轻步行走姿态 |
| states-atlas.png | 思考两帧、悬空两帧、坐下与困倦三帧、开心摸头一帧 |

`dragon-artwork.js` 在本地读取图集，统一比例与脚底基线，输出 400 × 600 的透明画布。坐下时不拉长身体，挥手时不随包围框宽度缩小角色。`dragon-life.js` 按动作节奏播放，拖动、点击、打字和工作状态优先于随机待机动作。遵守减少动态效果设置；窗口隐藏时停止逐帧切换。

`idle/wave/walk/think/dragged/pat/sleep.png` 是同一图集机械裁出的静态资源，用于首屏、头像及加载失败回退；无 AI 重绘。需要重新生成这些静态文件时运行：

```bash
node_modules/.bin/electron scripts/prepare-dragon-pet.cjs
```

Agent HUD 外部应用保持独立。项目自带额度 HUD 可从系统托盘的“独立显示 Agent 额度 HUD”开启，也可在桌宠设置开启“隐藏桌宠时保留额度 HUD”。关闭桌宠不再关闭独立 HUD，其额度刷新及趋势窗口照常工作。它是额度展示入口；DragonTAC 桌面会话连接能力以项目专项文档为准。

聊天与设置采用 Dragon 名称、头像和伙伴角色。既有历史故事及用户修改仍保留，故事中的神话人物属于原稿内容，不是桌宠身份。
