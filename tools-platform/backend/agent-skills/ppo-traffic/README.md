# 埃及车辆违章查询 Skill (PPO Traffic Violations)

本 Skill 对接埃及公诉机关（PPO）车辆违章查询服务，全员可用。

## 功能
- **违章查询**：支持中国护照与埃及身份证车主，输入车牌阿拉伯字母与纯数字，查询总罚金、违章总笔数与和解金。
- **状态监控**：检测官方系统与本地查询服务健康状态。
- **历史记录**：查看最近提交的查询明细。

## 使用方式
- **对话引用**：在首页或工作区输入 `@ppo-traffic` 或 `@埃及车辆违章查询`；也可以直接输入自然语言（例如“查一下车牌 أ ف س 3413、护照 E12345678 的违章”），系统将自动加载此技能。
- **CLI 调用**：
  ```bash
  python3 scripts/ppo_cli.py query --letters "أ ف س" --number 3413 --passport "E12345678" --wait
  ```
