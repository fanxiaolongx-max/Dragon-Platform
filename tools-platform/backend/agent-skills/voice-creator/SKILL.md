# 🎙️ 创建声音（Fish Audio 声音合成与语音创作）

目标：通过 Fish Audio 高拟真语音合成模型，将文字转化为自然逼真的音频。提供 12 款官方无版权安全音色供用户自由选择与互动，支持情感与副语言标记，自动输出播放器与下载链接。

基于 Fish Audio API 将文本合成为极高拟真度、自然连贯的语音音频。支持 12 种官方安全音色（可商业使用、非真人克隆无版权风险）、丰富的情感表现力标记，并与用户进行自然的音色交互选择。

## 🎯 核心工作流：引导用户交互选择声音

当用户提出需要合成语音、转换音频或朗读一段文字时：

1. **若用户未指定音色**：
   - **不要盲目使用默认声音默默生成**，应先主动向用户提供精选音色选项，引导用户挑选：
   - 推荐分类展示示例：
     - **播报/助手首选**：👩 **语彤**（女·利落自然，默认）/ 👨 **梓轩**（男·干练利落）
     - **教学辅导/耐心讲解**：👩 **晓彤**（女·亲切耐心，语言导师）
     - **陪伴漫谈/成熟沉稳**：👨 **建国**（男·北京腔磁性中年，温暖从容）
     - **情感治愈/温柔细腻**：👩 **雨薇**（女·温柔台湾腔，花艺师氛围）
     - **技术客服/专家顾问**：👨 **柏翰**（男·台湾腔专业自信）
   - 询问用户：“请问你希望使用哪种声音风格？你可以直接告诉我名字（如用晓彤），或者告诉我你想要的性别与风格。”
   - *注：若用户明确表示“随便/用默认/直接生成”，则直接选用默认的【语彤】生成。*

2. **若用户已明确指定音色**：
   - 直接调用 `voice_creator_generate` 工具生成音频。

## 🎭 表现力与情感控制语法（提升拟真度）

Fish Audio 支持在文本中直接嵌入情感与副语言标记：

* **括号情感提示**：在句子前或中间插入状态描述，如：
  * `[sigh]`（叹气）、`[cough]`（轻咳）、`[shaky breath]`（颤抖吸气）
  * `[barely holding it together, forcing a smile]`（强颜欢笑）
  * `[happy]`（开朗愉悦）、`[sad]`（伤心低沉）、`[angry]`（愤怒急促）
* **耳语音（私语）标签**：
  * `<whisper>悄悄告诉你一个小秘密。</whisper>`

## 🛠️ 可用原生工具

1. **`voice_creator_list_voices`**：
   - 查询声音清单。支持参数：`gender`（女性/男性/全部）、`accent`（大陆普通话/台湾普通话）。
2. **`voice_creator_generate`**：
   - 核心合成工具。
   - 参数：
     - `text`（必填）：要合成的文本。
     - `voice`（选填）：声音名称（如 `语彤`、`建国`、`雨薇`）或其 reference_id。
     - `format`（选填）：默认 `mp3`。
     - `model`（选填）：默认 `s2.1-pro-free`。
