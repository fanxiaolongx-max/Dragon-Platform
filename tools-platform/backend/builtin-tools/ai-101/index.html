LEVEL ONE

懂它

它是什么？为什么会一本正经地胡说？

学完能做到用一句话向同事讲清楚大模型
01一句话理解大模型

它是一个超级“接龙”高手

读过海量文字，学会了“下一个词最可能是什么”。一个词接一个词，写出整段回答。

它挑的是最像的下一个词，不是真实的答案；说得越顺，越容易当真。

所以：会写不等于查过，说得肯定不等于说得对。

01所以

长处和短处，都来自“接龙”

放心交给它
  • a
    写和改文字材料
  • b
    读和提炼既有材料
  • c
    翻译与解释不熟悉的表述
  • d
    脚本与公式可机械检查的规则
要盯着它
  • a
    不知道你没说的你没说出口的现场信息
  • b
    不知道最新发生的除非明确给它新信息
  • c
    会一本正经地编缺失的细节
  • d
    不为结果负责责任不会转移
01最好用的心智模型

把它当成一位读遍天下书，
但今天第一天入职的实习生。

i.

聪明勤快

→ 速度与产出都很好，值得用起来。

ii.

不了解现场

→ 交代清楚。你不说，它就靠猜。

iii.

不懂也敢答

→ 检查结果。它很少主动说“我不确定”。

LEVEL TWO

问它

同一个 AI，问法不同，结果天差地别。

学完能做到写出一段“拿来就能用”的提示词
02同一个需求，两种问法

它不是不聪明，是你没说清

大多数人这样问
一句话就问完，三要素都没给

→ 信息不全，它只能猜；每次猜的还不一样。

说清楚的问法
输入给它什么：格式、表头、版本、以哪份为准
处理逻辑怎么算、怎么判、查不到怎么办
输出要什么格式、哪些列、怎么交付
02方法

好提示词 = 输入 · 逻辑 · 输出

i.

输入

给它什么？
格式、表头、以哪份为准

ii.

处理逻辑

怎么算？怎么判？
查不到怎么办？

iii.

输出

要什么格式？
哪些列、怎么交付？

结尾加一句：“信息不够就先问我，不要猜。”

哪里不对？

3

具体、直接

4

直到能交付

i.

指位置

说清哪一处不对，不笼统说不好。

ii.

iii.

先问再写

缺信息时让它先提问，不要猜。

03上下文

AI 的“工作台”只有这么大

上下文窗口 · 以 TOKEN 计量
你的指令

Token 是模型读写文字的计量单位，不等于“一个字”。台面装满后，旧内容可能被截断或压缩。

没给它的
没上传的
不在本轮的
刚发生的

一句话管用：“以附件 X 为准；找不到就说没找到。”

03喂料的三条规矩

材料给得好，答案差不了

i.

标版本、标来源

文件名、日期、状态写清楚。别让它猜哪份是最新的、哪份是有效的。

ii.

说明以谁为准

指定唯一基准，其余只作参考；冲突时它才知道听谁的。

iii.

允许它说“没找到”

不给退路，它就会编一个答案给你。

长对话里，重要约束再说一遍；换了话题，就开个新对话；敏感数据，先脱敏再上传。

LEVEL FOUR

验它

AI 写初稿，人对结论负责。

学完能做到交付前，用四个问题过一遍
04AI 幻觉

一本正经地胡说，有三种样子

编数字

凭空补数

没给数据，也会凑一个看起来合理的数。

编因果

把先后当因果

两件事挨得近，就被连成因果关系。

编出处

引用打不开

看着有据可查，点开原文却没有。

凡是具体到数字、因果和出处的地方，都要能回到原始材料。

04交付前检查

发出去之前，过一遍四个问题

数字

有来源吗？

每个数字能指回原始数据。

因果

有证据吗？

“之后发生”不等于“因此发生”。

承诺

有授权吗？

时间、结论、对外表态，谁批准的？

出处

能打开吗？

点开原文，看那一段是否真这么写。

小技巧：要求 AI 每条结论后标注来源文件和章节，核对快十倍。
