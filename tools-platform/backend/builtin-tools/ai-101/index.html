LEVEL ONE

懂它

它是什么？为什么会一本正经地胡说？

学完能做到用一句话向同事讲清楚大模型
01一句话理解大模型

它是一个超级“接龙”高手

读过海量文字，学会了“下一个词最可能是什么”。一个词接一个词，写出整段回答。

它没查过任何数据，却给出了一个具体数字。
因为这样最顺口，不是因为真实。
01所以

长处和短处，都来自“接龙”

放心交给它
  • a
    写和改报告、方案、纪要、总结
  • b
    读和提炼长文档、规范、聊天记录
  • c
    翻译与解释英文资料、协议条款
  • d
    脚本与公式Python、Excel、正则
要盯着它
  • a
    不知道你没说的你的网络、你的项目、你的客户
  • b
    不知道最新发生的除非打开联网搜索
  • c
    会一本正经地编数字、原因、出处
  • d
    不为结果负责签字的永远是你
01最好用的心智模型

把它当成一位读遍天下书，
但今天第一天入职的实习生。

i.

聪明勤快

→ 大胆派活。初稿、整理、翻译，几秒就交。

ii.

不了解现场

→ 交代清楚。你不说，它就靠猜。

iii.

不懂也敢答

→ 检查结果。它很少主动说“我不确定”。

LEVEL TWO

问它

02同一个需求，两种问法

它不是不聪明，是你没说清

大多数人这样问
“帮我看看这个。”

→ 它只能猜你要什么，然后给你一个“看起来不错”的答案。

说清楚的问法
我要目标得到什么、给谁用。现在的情况是背景发生了什么。我提供了材料哪些资料，其中哪些已确认、哪些未知。注意约束不能猜什么、不能做什么。请按交付格式、长度、结构输出；信息不够就先问我。
02方法

好提示词 = 一份任务交底

i.

目标

要得到什么？
给谁用？

ii.

背景

现在是什么情况？
为什么要做？

iii.

材料

哪些已知？
哪些未知？

iv.

约束

什么不能猜？
什么不能做？

v.

交付

什么格式？
多长？

结尾加一句：“信息不够就先问我，不要猜。”

03喂料的三条规矩

材料给得好，答案差不了

i.

标版本、标来源

文件名、日期、状态写清楚。别让它猜哪份是最新的、哪份是有效的。

ii.

说明以谁为准

“以正式版为准，聊天记录仅供参考。”冲突时它才知道听谁的。

iii.

允许它说“没找到”

不给退路，它就会编一个答案给你。

长对话里，重要约束再说一遍；换了话题，就开个新对话；敏感数据，先脱敏再上传。

03最实用的一招

2

3

04AI 幻觉

一本正经地胡说，有三种样子

编数字

“大约提升了 37%”

你没给数据，它给你凑一个看起来合理的数。

编因果

“因为 A，所以 B”

两件事挨得近，它就把它们连成因果。

编出处

“根据某规范第 5.3 节”

看着有据可查，打开一看根本没有这一节。

现场时间：你被 AI 骗过吗？讲一次。

04交付前检查

发出去之前，过一遍四个问题

数字

有来源吗？

每个数字能指回原始数据。

因果

有证据吗？

“之后发生”不等于“因此发生”。

承诺

有授权吗？

时间、结论、对外表态，谁批准的？

出处

能打开吗？

点开原文，看那一段是否真这么写。

小技巧：要求 AI 每条结论后标注来源文件和章节，核对快十倍。
