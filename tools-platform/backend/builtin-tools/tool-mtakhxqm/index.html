核心规律小贴士 💡

Ibn (ابن / 伊本) = ...的儿子

Bint (بنت / 宾特) = ...的女儿

只要搞清长辈是 Amm(叔伯), Amma(姑), Khāl(舅), Khāla(姨)，前面加上 ibn / bint，长辈词使用“我的…”形式，就能组合出所有的表/堂亲称呼了！

性别区分注意 ⚠️

阿拉伯语中很多词区分说话人的性别。例如“想要”：男生说 'āyez (عايز)，女生说 'āyza (عايزة)。

为什么一个字母有多种读音？ 字母本身主要表示辅音，例如 بَ / بِ / بُ 分别读 ba / bi / bu，بْ 表示 b 后面没有元音。字母在词首、词中、词尾会改变形状，但通常仍是同一个音。埃及方言和标准语有差异的字母会在卡片下方特别标出。

埃及口语读写要点

字形不变，读音按词学习

ج 常读 g；ق 在开罗日常词中常为喉塞音 ʾ，但部分借词和正式词保留 q。ث、ذ、ظ 的读音依词而定，不能整页机械替换。

بَيْت 读 bēt，يَوْم 读 yōm。埃及口语中的 ē、ō 不能仅靠短音符号推算；单词转写和整词配音优先。

符号是学习辅助

日常聊天通常不写短元音。َ ِ ُ 是基本 a / i / u 提示，实际可接近 e / o；ْ 表示不带元音，辅音仍要发出；ّ 表示辅音延长或双写，不是重读符号。

ً ٍ ٌ 是书面语带 n 的词尾标记，日常埃及口语不套用格尾。固定表达 شكراً（shokran）、أهلاً（ahlan）保留 -an；抽查只在这些真实词里考察。

读写参考：Lisaan Masry 埃及口语发音。本课以开罗口语为基准；其他埃及地区可能有不同读法。

连写规则

关键点：阿拉伯语从右向左书写，并非所有字母都能连接左边的下一个字母。

✅ 可以向两侧连接：ب、ت、ث、ي

它们在单词中会根据位置呈现独立、词首、词中和词尾写法。

ب　بـ　ـبـ　ـب

🚫 不连接左边的下一个字母：ا、د、ذ、ر、ز、و

这六个字母可以接在前一个字母后面，但会让后续连接中断；ى 通常出现在词尾，也不再向后连接。

بـاـب ❌
错误：ا 后面仍画了连接线
بَاب ✅
正确：ا 后断开，最后的 ب 独立
